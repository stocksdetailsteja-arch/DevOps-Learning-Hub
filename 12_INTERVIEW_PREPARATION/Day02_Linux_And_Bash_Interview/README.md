# Day 02 - Linux And Bash Interview

## Objective

Prepare for Linux Administration and Bash Scripting interview questions ranging from beginner to advanced production-level scenarios.

## Why Linux Is Important

Almost every DevOps tool runs on Linux:

- Jenkins
- Docker
- Kubernetes
- Ansible
- Terraform
- Prometheus
- Grafana

A DevOps Engineer spends a significant amount of time troubleshooting Linux systems.

## Why Bash Is Important

Bash enables:

- Automation
- Monitoring
- Health Checks
- Log Analysis
- Deployment Automation
- Backup Automation

## Learning Outcomes

After completing this module you should be able to:

- Answer Linux interview questions confidently
- Troubleshoot Linux production issues
- Explain Bash scripts
- Write automation scripts
- Handle production support incidents
- Solve 5+ years experience questions
