# Day 07 - Kubernetes Interview

## Objective

Prepare for Kubernetes technical interviews from beginner to advanced production-support level.

## Why Kubernetes Is Important

Kubernetes manages containerized applications using declarative configuration and automation.

It supports:

- Application deployment
- Replica management
- Service discovery
- Load distribution
- Configuration management
- Secret references
- Storage
- Rolling updates
- Rollbacks
- Workload scaling
- Health management

## Learning Outcomes

After completing this module, you should be able to:

- Explain Kubernetes architecture
- Explain desired state and reconciliation
- Compare Pods, ReplicaSets and Deployments
- Explain Kubernetes networking
- Configure Services and external routing
- Explain ConfigMaps and Secrets
- Explain persistent storage
- Design health probes
- Configure resource requests and limits
- Explain workload scheduling
- Perform rolling updates and rollbacks
- Troubleshoot common production failures
- Answer scenario-based questions for five-plus years of experience
