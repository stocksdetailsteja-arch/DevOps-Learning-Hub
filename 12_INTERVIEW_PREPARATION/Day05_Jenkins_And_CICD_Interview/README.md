# Day 05 - Jenkins And CI/CD Interview

## Objective

Prepare for Jenkins and CI/CD technical interview rounds ranging from beginner to advanced production-level interviews.

## Why Jenkins Is Important

Jenkins is one of the most widely used CI/CD automation platforms.

Jenkins helps automate:

- Build
- Test
- Package
- Deploy
- Monitor

## Why CI/CD Is Important

CI/CD helps organizations:

- Deliver software faster
- Improve code quality
- Reduce deployment failures
- Standardize releases
- Automate repetitive tasks

## Learning Outcomes

After completing this module you should be able to:

- Explain Jenkins Architecture
- Design CI/CD Pipelines
- Secure Jenkins
- Troubleshoot failed builds
- Handle production incidents
- Answer advanced Jenkins questions
