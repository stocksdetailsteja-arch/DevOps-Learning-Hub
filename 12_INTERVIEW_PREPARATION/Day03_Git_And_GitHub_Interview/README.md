# Day 03 - Git And GitHub Interview

## Objective

Prepare for Git and GitHub interview questions from beginner to advanced production support level.

## Why Git Is Important

Git is the foundation of DevOps because every automation platform depends on version-controlled code.

Used by:

- Jenkins
- GitHub Actions
- Terraform
- Ansible
- Kubernetes
- Docker

## Why GitHub Is Important

GitHub provides:

- Code Hosting
- Collaboration
- Pull Requests
- Code Reviews
- CI/CD Integration
- Branch Protection

## Learning Outcomes

By the end of this module you will be able to:

- Explain Git architecture
- Manage branches effectively
- Resolve merge conflicts
- Recover deleted commits
- Handle GitHub workflows
- Troubleshoot Git issues
- Answer production-level interview questions
