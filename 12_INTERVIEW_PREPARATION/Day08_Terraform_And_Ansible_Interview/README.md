# Day 08 - Terraform And Ansible Interview

## Objective

Prepare for Terraform and Ansible technical interviews from beginner to advanced production-support level.

## Why Terraform Is Important

Terraform enables teams to create and manage infrastructure through version-controlled declarative configuration.

Terraform supports:

- Infrastructure provisioning
- Resource dependency management
- Reusable modules
- Remote state
- State locking
- Change planning
- Drift detection
- Resource import
- Controlled infrastructure destruction

## Why Ansible Is Important

Ansible automates configuration management and application deployment across managed systems.

Ansible supports:

- Package installation
- User management
- Service configuration
- Application deployment
- File and template management
- Reusable roles
- Secret encryption
- Controlled multi-host rollouts
- Compliance and configuration enforcement
