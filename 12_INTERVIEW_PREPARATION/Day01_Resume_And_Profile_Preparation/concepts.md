# Resume Concepts

## ATS (Applicant Tracking System)

Many companies use ATS software to filter resumes.

Examples:

- Workday
- Taleo
- SuccessFactors
- Greenhouse

## ATS Friendly Resume

Characteristics:

- Simple layout
- Clear headings
- Keywords matching job description
- Standard fonts
- Proper section ordering

## Professional Summary

Must clearly communicate:

- Total Experience
- Current Role
- Technical Skills
- Domain Expertise

Example:

Senior Software Engineer with 5+ years of experience in Java, Spring Boot, AWS, Docker, Kubernetes, Jenkins and Terraform.

## Technical Skills Section

Group skills by category:

### Cloud

- AWS

### Containers

- Docker
- Kubernetes

### CI/CD

- Jenkins
- GitHub

### IaC

- Terraform
- Ansible

### Monitoring

- Prometheus
- Grafana

## Resume Achievement Formula

Action + Technology + Impact

Example:

Implemented Jenkins CI/CD pipeline reducing deployment time from 45 minutes to 10 minutes.

## GitHub Portfolio

Must contain:

- README
- Architecture diagrams
- Screenshots
- Lab Evidence
- Troubleshooting Notes

## LinkedIn Profile

Key Sections:

- Headline
- About
- Experience
- Projects
- Skills
- Certifications

## Recruiter Expectations

Recruiters want to know:

- What you do
- What technologies you use
- Your project impact
- Your communication skills
