# AWS Cloud Concepts

## AWS Global Infrastructure

Region

↓

Availability Zone

↓

Data Center

## Region

Geographical AWS location.

Examples:

- us-east-1
- ap-south-1

## Availability Zone

Independent data center inside a region.

## IAM

Identity and Access Management.

Used for:

- Users
- Groups
- Roles
- Policies

## EC2

Elastic Compute Cloud.

Provides virtual machines.

## EBS

Elastic Block Storage.

Persistent disk storage.

## S3

Object storage service.

Common Use Cases:

- Backups
- Static Websites
- Artifacts

## VPC

Virtual Private Cloud.

Provides isolated cloud network.

## Subnets

Logical divisions inside VPC.

Types:

- Public
- Private

## Security Group

Instance-level firewall.

Stateful.

## NACL

Subnet-level firewall.

Stateless.

## Load Balancer

Distributes traffic across targets.

## Auto Scaling

Automatically adjusts instance counts.

## RDS

Managed relational database service.

## CloudWatch

Provides:

- Metrics
- Logs
- Alarms
- Dashboards

## CloudTrail

Tracks AWS API activities.

## Secrets Manager

Securely stores credentials.

## Shared Responsibility Model

AWS:

Security Of Cloud

Customer:

Security In Cloud
