# Day 01 - Git Interview Questions

## Basic

### Q1 What Is Git?

Git is a Distributed Version Control System.

### Q2 What Is Version Control?

A system that tracks file changes over time.

### Q3 What Is A Repository?

A Git-managed project directory.

## Intermediate

### Q1 Difference Between Git And GitHub?

Git:

Version Control Tool.

GitHub:

Cloud Hosting Platform for Git repositories.

### Q2 What Is A Commit?

A snapshot of project changes.

### Q3 What Is The Staging Area?

An intermediate area between working directory and repository.

## Advanced (5+ Years)

### Q1 Explain Git Architecture.

Answer:

Working Directory

↓

Staging Area

↓

Local Repository

↓

Remote Repository

### Q2 Why Is Git Important In DevOps?

Answer:

Git acts as the source of truth for:

- Source Code

- Infrastructure Code

- Configuration Files

- CI/CD Pipelines

### Q3 What Happens Internally During git commit?

Answer:

Git creates a snapshot and stores metadata including:

- Commit ID

- Author

- Timestamp

- Commit Message

### Q4 Why Should Commits Be Small?

Answer:

Benefits:

- Easier Review

- Easier Rollback

- Better Troubleshooting

- Cleaner History
