# Day 01 - Git Introduction Lab Notes

## Objective

Learn Git fundamentals and local repository management.

## Commands Executed

- git init

- git status

- git add

- git commit

- git log

## Observations

- Git tracks file changes.

- Staging area prepares changes for commit.

- Commits create history.

## Results

Successfully created Git repository and committed changes.

## Lessons Learned

- Always check git status.

- Use meaningful commit messages.

- Commit small logical changes.
