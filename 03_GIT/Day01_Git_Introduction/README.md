# Day 01 - Git Introduction

## Overview

This module introduces Git, Version Control Systems, Repositories, Commits, Working Directory, Staging Area, and the Git Lifecycle.

Git is the most widely used Version Control System in the software industry and is a core skill for DevOps Engineers.

## Learning Objectives

- Understand Version Control

- Understand Git Architecture

- Create Git Repositories

- Track Changes

- Commit Changes

- View History

- Understand Git Workflow

## Topics Covered

- What Is Git

- What Is Version Control

- Repository

- Working Directory

- Staging Area

- Commit

- Git Lifecycle

- Git Architecture

## DevOps Relevance

Git is used in:

- Jenkins

- GitHub Actions

- Azure DevOps

- GitLab CI/CD

- Kubernetes GitOps

- Terraform Modules
