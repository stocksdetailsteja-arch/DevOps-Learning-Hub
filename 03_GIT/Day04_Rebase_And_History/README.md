# Day 04 - Rebase And History

## Overview

This module covers Git Rebase, Interactive Rebase, Commit Squashing, Cherry Pick, Reflog, Reset, Restore, and History Management.

Rebase helps maintain clean Git history and is heavily used in enterprise development environments.
