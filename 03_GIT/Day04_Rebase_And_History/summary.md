## Quick Revision

Rebase → Linear History

Squash → Combine Commits

Cherry Pick → Copy Commit

Reflog → Recovery Tool

Reset → Move Branch Pointer

Restore → Restore Files

## Production Notes

- Rebase before Pull Requests when policy permits.

- Avoid rewriting shared branch history.

- Use reflog for recovery.

- Verify before using hard reset.

## Key Takeaways

- Clean history improves collaboration.

- Reflog is a lifesaver.

- Rebase is commonly asked in DevOps interviews.
