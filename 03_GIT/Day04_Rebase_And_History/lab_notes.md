# Day 04 - Rebase And History Lab Notes

## Objective

Learn Git history manipulation and recovery techniques.

## Commands Executed

- git rebase

- git rebase -i

- git cherry-pick

- git reflog

- git reset

- git restore

## Observations

- Rebase creates cleaner history.

- Reflog is useful for recovery.

- Cherry-pick moves specific changes.

## Results

Successfully rebased branches and recovered history.

## Lessons Learned

- Avoid unnecessary commits.

- Keep history clean.

- Reflog can save lost work.
