# Day 08 - Git Best Practices Lab Notes

## Objective

Learn Git standards followed in real enterprise environments.

## Commands Executed

- git commit

- git log

- git checkout

- git status

## Observations

- Repository structure matters.

- Commit messages improve readability.

- .gitignore prevents unnecessary files.

## Results

Successfully implemented Git standards.

## Lessons Learned

- Small commits are easier to review.

- Feature branches improve collaboration.

- Never commit secrets.
