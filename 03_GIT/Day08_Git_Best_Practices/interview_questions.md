# Day 08 - Interview Questions

## Basic

### Q1 What Is .gitignore?

Used to exclude files from Git tracking.

### Q2 Why Use Commit Standards?

To maintain clean history.

## Intermediate

### Q1 What Should Never Be Committed?

- Passwords

- API Keys

- Tokens

- Certificates

- Environment Files

### Q2 Why Use Feature Branches?

To isolate changes.

## Advanced (5+ Years)

### Q1 What Git Standards Have You Followed In Enterprise Projects?

Answer:

- Feature Branch Strategy

- Pull Request Reviews

- Commit Standards

- Branch Protection

- Release Tagging

### Q2 Why Are Small Commits Better?

Answer:

Benefits:

- Easier Reviews

- Easier Rollbacks

- Better History

- Faster Troubleshooting

### Q3 How Do You Prevent Secrets From Entering Git?

Answer:

- .gitignore

- Secret Scanning

- Pre-Commit Validation

- Secure Credential Stores

### Q4 Explain Branch Naming Conventions.

Answer:

feature/

bugfix/

hotfix/

release/

These improve repository organization.
