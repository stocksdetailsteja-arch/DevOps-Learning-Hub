# Day 03 - Merging And Conflicts

## Overview

This module covers Git Merging, Fast Forward Merge, Three-Way Merge, Merge Commits, Merge Conflicts, Conflict Resolution, and Real-World Team Collaboration.

Merging is the process of combining changes from one branch into another.

- Perform Branch Merges

- Understand Fast Forward Merge

- Understand Three-Way Merge

- Resolve Merge Conflicts

- Analyze Merge History
