# Day 03 - Interview Questions

## Basic

### Q1 What Is Git Merge?

Git Merge combines changes from one branch into another.

### Q2 What Is Fast Forward Merge?

A merge where no merge commit is required.

### Q3 What Is A Merge Conflict?

Occurs when Git cannot automatically combine changes.

## Intermediate

### Q1 Difference Between Fast Forward And Three-Way Merge?

Fast Forward:

No merge commit.

Three-Way:

Creates merge commit.

### Q2 How Do You Resolve A Merge Conflict?

Answer:

Open conflicting file

Review markers

Choose correct content

Save file

git add

git commit

## Advanced (5+ Years)

### Q1 How Are Feature Branches Merged In Enterprise Development?

Answer:

Feature Branch

↓

Pull Request

↓

Code Review

↓

CI Validation

↓

Merge To Main

### Q2 Why Are Merge Conflicts Common?

Answer:

Multiple developers modifying identical sections of code.

### Q3 How Does Jenkins Use Merged Code?

Answer:

Jenkins triggers build using the merged branch content.

Pipeline execution begins after successful merge.

### Q4 What Happens Internally During Three-Way Merge?

Answer:

Git finds:

- Common Ancestor

- Main Branch Changes

- Feature Branch Changes

Then calculates merge result.
