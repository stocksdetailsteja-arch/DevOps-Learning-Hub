# Day 03 - Merging And Conflicts Lab Notes

## Objective

Learn Git Branch Integration and Conflict Resolution.

## Commands Executed

- git merge

- git log

- git add

- git commit

## Observations

- Git automatically merges when possible.

- Conflicts require manual resolution.

- Merge history can be visualized.

## Results

Successfully performed merges and conflict resolution.

## Lessons Learned

- Branching improves collaboration.

- Conflicts are normal.

- Proper resolution prevents code loss.
