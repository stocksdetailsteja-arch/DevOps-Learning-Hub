# Day 06 - GitHub Workflow Lab Notes

## Objective

Learn collaboration using GitHub workflow.

## Commands Executed

- git clone

- git checkout

- git add

- git commit

- git push

- git pull

## Observations

- Pull Requests improve quality.

- Feature branches isolate development.
