# Day 06 - Interview Questions

## Basic

### Q1 What Is A Pull Request?

A request to merge code from one branch into another.

### Q2 Why Use Pull Requests?

For review and approval before merging.

### Q3 What Is A Fork?

Personal copy of a repository.

## Intermediate

### Q1 Difference Between Fork And Clone?

Fork:

Creates GitHub copy.

Clone:

Creates local copy.

### Q2 Why Are Code Reviews Important?

Improve quality and detect issues.

## Advanced (5+ Years)

### Q1 Explain Enterprise GitHub Workflow.

Answer:

Feature Branch

↓

Development

↓

Push

↓

Pull Request

↓

Review

↓

CI Validation

↓

### Q2 Why Protect Main Branch?

Answer:

Prevent:

- Direct Commits

- Accidental Changes

- Unreviewed Code

### Q3 How Does Jenkins Integrate With Pull Requests?

Answer:

Pull Request Created

↓

Jenkins Triggered

↓

Build Validation

↓

Merge Decision

### Q4 What GitHub Workflow Have You Used?

Answer:

Most teams use:

- Feature Branch Workflow

- Pull Requests

- Branch Protection

- Automated CI Validation
