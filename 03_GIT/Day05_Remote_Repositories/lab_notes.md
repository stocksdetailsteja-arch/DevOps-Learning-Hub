# Day 05 - Remote Repositories Lab Notes

## Objective

Learn GitHub integration and remote repository management.

## Commands Executed

- git remote

- git clone

- git push

- git pull

- git fetch

## Observations

- GitHub acts as centralized storage.

- Push uploads local changes.

- Pull downloads remote updates.

## Results

Successfully synchronized local and remote repositories.

## Lessons Learned

- Always pull before starting work.

- Push frequently.

- Verify branch before pushing.
