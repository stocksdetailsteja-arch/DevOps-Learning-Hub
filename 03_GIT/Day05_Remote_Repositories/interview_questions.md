# Day 05 - Interview Questions

## Basic

### Q1 What Is A Remote Repository?

A Git repository hosted on a remote server.

### Q2 What Is git clone?

Creates a local copy of a remote repository.

### Q3 What Is git push?

Uploads local commits to remote repository.

## Intermediate

### Q1 Difference Between Pull And Fetch?

Fetch:

Downloads changes only.

Pull:

Downloads and merges changes.

### Q2 What Is Origin?

Default name of a remote repository.

### Q3 What Is Upstream Branch?

A local branch linked to a remote branch.

## Advanced (5+ Years)

### Q1 What Happens Internally During git push?

Answer:

Git identifies missing commits.

Git transfers objects.

Remote updates branch reference.

Remote history is updated.

### Q2 Why Do Enterprise Teams Prefer SSH?

Answer:

- Secure Authentication

- Key-Based Access

- No Repeated Password Prompts

### Q3 Why Is git fetch Safer Than git pull?

Answer:

Fetch allows review before merging.

Pull automatically merges.
