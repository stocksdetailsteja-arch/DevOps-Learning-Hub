# Day 07 - Git Tags And Releases

## Overview

This module covers Git Tags, Lightweight Tags, Annotated Tags, Semantic Versioning, GitHub Releases, Release Management, and Production Deployment Strategies.

Tags are used to mark important points in Git history, typically production releases.

- Understand Git Tags

- Create Lightweight Tags

- Create Annotated Tags

- Push Tags To GitHub

- Create Releases
