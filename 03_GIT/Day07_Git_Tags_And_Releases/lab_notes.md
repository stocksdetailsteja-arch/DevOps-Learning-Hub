# Day 07 - Lab Notes

## Objective

Learn versioning and release management using Git Tags.

## Commands Executed

- git tag

- git show

- git push origin tag

- git push origin --tags

## Observations

- Tags mark important commits.

- Releases simplify deployments.

- Semantic Versioning provides structure.

## Results

Successfully created and managed Git tags.

## Lessons Learned

- Every production release should use tags.

- Tags simplify rollback and auditing.
