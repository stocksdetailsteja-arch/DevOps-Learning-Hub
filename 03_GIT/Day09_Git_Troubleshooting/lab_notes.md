# Day 09 - Git Troubleshooting Lab Notes

## Objective

Learn Git recovery and troubleshooting scenarios.

## Commands Executed

- git reflog

- git stash

- git reset

- git revert

- git checkout

## Observations

- Most lost work can be recovered.

- Reflog is extremely valuable.

- Revert is safer than reset on shared branches.

## Results

Successfully recovered commits and branches.

## Lessons Learned

- Avoid unnecessary hard resets.

- Use reflog before panicking.

- Verify branch before destructive operations.
