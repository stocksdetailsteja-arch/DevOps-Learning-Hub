# Day 02 - Git Branches Lab Notes

## Objective

Learn Git branch management and feature development workflow.

## Commands Executed

- git branch

- git checkout

- git switch

- git branch -d

## Observations

- Branches isolate development.

- Multiple branches can exist simultaneously.

- HEAD tracks current branch.

## Results

Successfully created, switched, and deleted Git branches.

## Lessons Learned

- Create branches for every feature.

- Never develop directly on production branches.

- Use meaningful branch names.
