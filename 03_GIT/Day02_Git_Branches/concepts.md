# Day 02 - Git Branches Concepts

## What Is A Branch?

A branch is an independent line of development.

It allows developers to work on new features without affecting the main code.

## Why Branches Are Important?

Benefits:

- Parallel Development

- Safe Experimentation

- Better Team Collaboration

- Easier Testing

- Controlled Releases

## What Is HEAD?

HEAD is a pointer that indicates the currently checked-out branch.

Example:

HEAD → main

HEAD → feature-login

## Default Branch

Common default branches:

- main

- master

Most modern repositories use:

main

## Feature Branch Workflow

main

↓

Create Feature Branch

↓

Implement Changes

↓

Commit Changes

↓

Merge Back

This is the most common workflow used in DevOps teams.

## Branch Lifecycle

Create Branch

↓

Switch Branch

↓

Develop Feature

↓

Commit Changes

↓

Merge Branch

↓

Delete Branch
