# Day 02 - Git Branches

## Overview

This module covers Git Branching, HEAD, Branch Creation, Branch Switching, Branch Deletion, and Feature Branch Workflow.

Branching is one of the most important Git concepts because development teams work on separate branches before merging code into the main branch.
