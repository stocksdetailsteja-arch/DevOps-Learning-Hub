# AWS Interview Cheatsheet

## What Is AWS?

Amazon Web Services cloud platform.

## What Is IAM?

Identity And Access Management.

Used for:

- Users
- Groups
- Roles
- Policies

## IAM Role Vs User

User:

Permanent Identity

Role:

Temporary Permissions

## What Is EC2?

Virtual Machine Service.

## What Is EBS?

Block Storage.

Attached to EC2.

## What Is S3?

Object Storage Service.

## EBS Vs S3

EBS:

Block Storage

S3:

Object Storage

## What Is VPC?

Virtual Private Cloud.

Private Network In AWS.

## Public Subnet

Connected to Internet Gateway.

## Private Subnet

No Direct Internet Access.

## Security Group

Instance-Level Firewall.

Stateful.

## NACL

Subnet-Level Firewall.

Stateless.

## Security Group Vs NACL

Security Group:

Stateful

Instance Level

NACL:

Stateless

Subnet Level

## What Is Route Table?

Controls Network Routing.

## What Is Load Balancer?

Distributes Incoming Traffic.

## Types Of Load Balancer

- ALB
- NLB
- GWLB

## What Is Auto Scaling?

Automatically adjusts EC2 count.

## RDS

Managed Relational Database.

## CloudWatch

Monitoring Service.

## CloudTrail

Audit Service.

Tracks API Calls.

## S3 Storage Classes

- Standard
- IA
- One Zone IA
- Glacier
- Deep Archive

## Shared Responsibility Model

AWS:

Security OF Cloud

Customer:

Security IN Cloud
