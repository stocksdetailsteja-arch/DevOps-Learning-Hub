# Git & GitHub Interview Cheatsheet

## What Is Git?

Distributed Version Control System.

## What Is GitHub?

Cloud-based Git repository hosting platform.

## Git Vs GitHub

Git:

Version Control Tool

GitHub:

Repository Hosting Platform

## What Is Repository?

Storage area for project files and history.

## What Is Commit?

Snapshot of code changes.

## What Is Branch?

Independent line of development.

## What Is Merge?

Combining code from two branches.

## What Is Rebase?

Moves commits on top of another branch.

Creates cleaner history.

## What Is HEAD?

Pointer to current commit.

## What Is Detached HEAD?

HEAD points directly to commit.

Not branch.

## What Is Stash?

Temporary storage for uncommitted changes.

## What Is Cherry Pick?

Apply specific commit from another branch.

## What Is Tag?

Version marker.

Example:

v1.0

v2.0

## Merge Vs Rebase

Merge:

Preserves history.

Rebase:

Creates linear history.

## Reset Vs Revert

Reset:

Changes history.

Revert:

Creates opposite commit.

Safe for production.

## What Is Pull Request?

Request to merge code into another branch.

## Why Use Pull Requests?

- Review
- Approval
- Quality Control

## What Is Branch Protection?

Prevents accidental changes to important branches.

Examples:

- main
- production
