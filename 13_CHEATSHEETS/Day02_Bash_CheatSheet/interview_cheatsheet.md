# Bash Interview Cheatsheet

## What Is Bash?

Bourne Again Shell.

Command interpreter for Linux.

## Why Use Bash?

- Automation
- Monitoring
- Deployment
- Scheduling
- Administration

## What Is A Shell?

Interface between user and operating system.

## What Is Shebang?

#!/bin/bash

Defines script interpreter.

## Difference Between $@ And $*?

$@

Passes arguments separately.

$*

Passes all arguments as single string.

## What Is Exit Code?

Command execution status.

0 = Success

Non-Zero = Failure

## What Is $? Variable?

Stores last command exit status.

## What Is Difference Between Break And Continue?

break

Stops loop.

continue

Skips current iteration.

## What Is Function?

Reusable code block.

## What Is Cron?

Linux scheduler used for automation.

## What Is Environment Variable?

System-wide variable.

Examples:

PATH

HOME

USER

## What Is Command Substitution?

output=$(date)

Stores command output.

## What Is Redirection?

>

Overwrite file.

>>

Append file.

2>

Redirect errors.

## What Is Pipe?

|

Pass output of one command to another.

## What Is Grep?

Search text pattern.

## What Is Awk?

Pattern scanning and processing.

## What Is Sed?

Stream editor.
