## Interview Explanation

### Situation

Manual Linux health checks were repetitive and inconsistent.

### Task

Build a reusable automation tool that checks server health and generates actionable results.

### Action

Created a modular Bash solution with configurable thresholds, structured logs, exit codes, service validation, network checks, and systemd scheduling.

Tested successful, warning, and critical conditions.

Documented investigation, recovery, rollback, and cleanup procedures.

### Result

Created a repeatable Linux operations project that can be demonstrated through source code, logs, systemd execution, screenshots, and controlled failure recovery.

## Future Enhancements

- JSON output
- Prometheus integration
- CloudWatch custom metrics
- Webhook notifications
- Automated Bash tests
- ShellCheck pipeline
- Ansible deployment
- Multi-server reporting
