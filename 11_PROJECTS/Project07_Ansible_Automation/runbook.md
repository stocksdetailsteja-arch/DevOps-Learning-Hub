# Operations Runbook

## Daily Validation

- Inventory validation
- Connectivity validation
- Playbook syntax check
- Dry run execution

## Incident Handling

1. Identify error
2. Validate inventory
3. Validate connectivity
4. Review logs
5. Apply fix
6. Re-run playbook
7. Validate service

## Change Procedure

1. Update role
2. Syntax check
3. Dry run
4. Approve
5. Execute
6. Validate
