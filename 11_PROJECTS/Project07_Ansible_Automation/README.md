# Project 07 - Ansible Automation

## Project Title

Configuration Management And Application Automation Using Ansible

## Objective

Automate Linux server configuration and application deployment using reusable Ansible playbooks and roles.

## Business Problem

Manual server configuration results in:

- Configuration drift
- Inconsistent environments
- Human errors
- Slow deployments
- Difficult troubleshooting

## Solution

Use Ansible automation for:

- Linux configuration
- Package installation
- User management
- Service management
- Nginx deployment
- Configuration files
- Application deployment
- Validation

## Technologies

- Ansible
- Linux
- SSH
- Ubuntu
- Nginx
- Jinja2 Templates
- YAML

- Inventory
- Roles

- Templates
