# Operations Runbook

## Daily Checks

- EC2 Health
- ALB Health
- Target Health
- RDS Status
- CloudWatch Alarms

## Incident Response

1. Identify alert
2. Validate affected service
3. Check CloudWatch metrics
4. Check networking
5. Apply recovery
6. Validate solution
7. Update documentation

## Escalation Evidence

- Alarm screenshot
- CloudWatch metrics
- EC2 status
- ALB target health
- Logs
