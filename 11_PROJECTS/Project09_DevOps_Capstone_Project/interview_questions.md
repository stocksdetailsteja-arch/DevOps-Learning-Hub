## Advanced (5+ Years)

### Explain A Production Incident.

Problem:

Deployment succeeded.

Users received 503 errors.

Investigation:

- Ingress
- Service
- Endpoints
- Pods
- Application logs

Root Cause:

Service selector mismatch.

Resolution:

Correct labels.

Re-deploy.

Validate endpoints.

### Explain Blue-Green Deployment.

Two identical environments.

Traffic moved after validation.

### Explain Canary Deployment.

Traffic released gradually.

Metrics monitored before full rollout.

### Explain End-To-End Monitoring Strategy.

- Infrastructure Metrics
- Application Metrics
- Logs
- Alerts
- Dashboards
- Runbooks
