# Day 02 - Kubernetes Architecture Troubleshooting

## Scenario 1

Cannot Connect To API Server

Cause:

API Server Unavailable

Resolution:

Verify Cluster Health.

## Scenario 2

Node Not Ready

Cause:

Kubelet Issue

Resolution:

Review Node Status.

## Scenario 3

Pod Not Scheduled

Cause:

Resource Constraints

Resolution:

Review Scheduler Events.

## Scenario 4

Service Communication Failure

Cause:

Network Issue

Resolution:

Review Kube Proxy.

## Scenario 5 (5+ Years)

ETCD Performance Issue

Investigation:

- ETCD Health

- Latency

- Storage

Resolution:

Review ETCD Infrastructure.

## Scenario 6 (5+ Years)

Control Plane Slow

Investigation:

- API Server

- Controller Manager

- Scheduler

Resolution:

Identify Bottleneck.

## Scenario 7 (5+ Years)

Cluster Instability

Investigation:

- Nodes

- Control Plane

- Events

- Storage

Resolution:

Analyze Cluster Components.
