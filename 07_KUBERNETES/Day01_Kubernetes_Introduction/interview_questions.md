# Day 01 - Interview Questions

## Basic

### Q1 What Is Kubernetes?

Kubernetes is an open-source platform for deploying, scaling, and managing containerized applications.

### Q2 What Is Container Orchestration?

Automated management of containers.

### Q3 Why Is Kubernetes Needed?

To manage containers at scale.

### Q4 What Is kubectl?

Command-line tool used to interact with Kubernetes.

## Intermediate

### Q1 Difference Between Docker And Kubernetes?

Docker:

Container Runtime

Kubernetes:

Container Orchestration Platform

### Q2 What Is A Kubernetes Cluster?

Collection of nodes managed by Kubernetes.

### Q3 What Are Kubernetes Features?

- Self Healing

- Scaling

- Load Balancing

- Rolling Updates
