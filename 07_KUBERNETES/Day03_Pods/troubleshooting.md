# Day 03 - Kubernetes Pods Troubleshooting

## Scenario 1

Pod Pending

Cause:

Scheduling Issue

Resolution:

Review Events.

## Scenario 2

Pod Failing

Cause:

Container Error

Resolution:

Check Logs.

## Scenario 3

CrashLoopBackOff

Cause:

Application Startup Failure

Resolution:

Review Application Logs.

## Scenario 4

ImagePullBackOff

Cause:

Image Not Available

Resolution:

Validate Container Image.

## Scenario 5 (5+ Years)

Production Pod Restarting Frequently

Investigation:

- Logs

- Resource Usage

- Health Checks

Resolution:

Identify Application Failure.

## Scenario 6 (5+ Years)

Pod Not Scheduled

Investigation:

- Nodes

- Resources

- Scheduler Events

Resolution:

Correct Scheduling Constraints.

## Scenario 7 (5+ Years)

Application Slow Inside Pod

Investigation:

- CPU

- Memory

- Logs

- Application Metrics

Resolution:

Optimize Application Or Resources.
