## Quick Revision

Service → Stable Access

ClusterIP → Internal Service

NodePort → External Access

LoadBalancer → Cloud Exposure

Endpoints → Backend Pods

## Production Notes

- Use Services Instead Of Pod IPs

- Verify Endpoints

- Monitor Service Health

- Use DNS-Based Communication

## Key Takeaways

- Services provide stable networking.

- Endpoints connect Services to Pods.

- DNS simplifies communication.

- Load balancing is built into Kubernetes Services.
