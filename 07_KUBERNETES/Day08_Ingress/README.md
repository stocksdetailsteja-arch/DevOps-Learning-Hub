# Day 08 - Kubernetes Ingress

## Overview

This module covers Kubernetes Ingress, Ingress Controllers, Host-Based Routing, Path-Based Routing, TLS/SSL, Load Balancing, URL Routing, and Production Traffic Management.

Ingress provides a centralized way to expose applications running inside Kubernetes clusters.

- Understand Kubernetes Ingress

- Understand Ingress Controller

- Configure Host-Based Routing

- Configure Path-Based Routing

- Configure TLS/SSL

- Manage External Traffic

- Implement Load Balancing
