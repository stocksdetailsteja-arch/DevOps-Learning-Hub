# Day 08 - Interview Questions

## Basic

### Q1 What Is Ingress?

Kubernetes object for managing HTTP/HTTPS traffic.

### Q2 Why Is Ingress Needed?

Centralized traffic management.

### Q3 What Is An Ingress Controller?

Component that processes Ingress rules.

### Q4 What Is Host-Based Routing?

Routing traffic using domain names.

## Intermediate

### Q1 Difference Between Service And Ingress?

Service:

Exposes Application

Ingress:

Routes Traffic To Services

### Q2 What Is Path-Based Routing?

Routing using URL paths.

### Q3 Why Use TLS In Ingress?

Secure communication using HTTPS.
