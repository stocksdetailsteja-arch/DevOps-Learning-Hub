# Day 10 - Real World Kubernetes Project Troubleshooting

## Scenario 1

Pods Pending

Cause:

Insufficient Resources

Resolution:

Review Requests, Limits, And Node Capacity.

## Scenario 2

CrashLoopBackOff

Cause:

Startup Failure

Resolution:

Review Logs And Probes.

## Scenario 3

Ingress Not Working

Cause:

Controller Or Configuration Issue

Resolution:

Review Ingress Rules And Endpoints.

## Scenario 4

Readiness Probe Failing

Cause:

Application Not Ready

Resolution:

Review Startup Behavior.

## Scenario 5 (5+ Years)

Rolling Update Stuck

Investigation:

- Events

- New Pods

- Probes

- Resources

Resolution:

Fix New Version Or Rollback.

## Scenario 6 (5+ Years)

Production Outage

Investigation:

- Service

- Endpoints

- DNS

- Ingress

- Application Health

Resolution:

Follow Incident Response Process.

## Scenario 7 (5+ Years)

Security Incident

Investigation:

- Secrets

- Access Controls

- Audit Logs

Resolution:

Rotate Credentials And Restrict Access.
