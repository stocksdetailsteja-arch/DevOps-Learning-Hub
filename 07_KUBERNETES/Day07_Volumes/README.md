# Day 07 - Kubernetes Volumes

## Overview

This module covers Kubernetes Persistent Volumes (PV), Persistent Volume Claims (PVC), Storage Classes, Dynamic Provisioning, Stateful Applications, Data Persistence, and Production Storage Management.

Applications often require storage that survives Pod restarts and recreation.

Kubernetes provides persistent storage solutions through PVs and PVCs.

- Understand Persistent Volumes

- Understand Persistent Volume Claims

- Understand Storage Classes

- Configure Persistent Storage
