# Day 07 - Lab Notes

## Objective

Learn Kubernetes persistent storage concepts.

## Services Used

- Persistent Volumes

- Persistent Volume Claims

- Storage Classes

## Observations

- PV provides storage.

- PVC consumes storage.

- StorageClass automates provisioning.

- Data survives Pod recreation.

## Results

Successfully implemented persistent storage.

## Lessons Learned

- Storage is critical for stateful workloads.

- PVC simplifies storage usage.

- Dynamic provisioning improves automation.
