# Day 04 - Kubernetes Deployments Troubleshooting

## Scenario 1

Deployment Not Created

Cause:

Configuration Error

Resolution:

Review Deployment Configuration.

## Scenario 2

Scaling Not Working

Cause:

Deployment Issue

Resolution:

Review ReplicaSet Status.

## Scenario 3

Update Failed

Cause:

Image Problem

Resolution:

Verify Image Availability.

## Scenario 4

Pods Not Running

Cause:

Container Failure

Resolution:

Review Events And Logs.

## Scenario 5 (5+ Years)

Production Rollout Failure

Investigation:

- Rollout Status

- Events

- Logs

Resolution:

Rollback Deployment.

## Scenario 6 (5+ Years)

ReplicaSet Not Maintaining Pod Count

Investigation:

- Deployment Health

- Node Status

- Scheduler Events

Resolution:

Review Cluster Health.

## Scenario 7 (5+ Years)

High Deployment Failure Rate

Investigation:

- Image Quality

- Resource Allocation

- Deployment Process

Resolution:

Implement Deployment Validation.
