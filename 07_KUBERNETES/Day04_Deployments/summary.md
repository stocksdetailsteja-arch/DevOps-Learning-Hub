# Day 04 - Summary

## Topics Covered

- Deployments

- ReplicaSets

- Scaling

- Rolling Updates

- Rollbacks

## Commands Learned

- kubectl create deployment

- kubectl get deployments

- kubectl scale deployment

- kubectl rollout status

- kubectl rollout undo

## Quick Revision

Deployment → Pod Manager

ReplicaSet → Pod Availability

Scale → Increase/Decrease Replicas

Rolling Update → Zero Downtime Update

Rollback → Revert Version

## Production Notes

- Use Deployments For Applications

- Configure Multiple Replicas

- Monitor Rollouts

- Always Have Rollback Plans

## Key Takeaways

- Deployments are the standard Kubernetes workload object.

- ReplicaSets maintain availability.

- Rolling updates minimize downtime.

- Rollbacks improve operational safety.
