# Day 06 - Lab Notes

## Objective

Learn Kubernetes ConfigMaps and Secrets.

## Services Used

- ConfigMaps

- Secrets

- Pods

- Environment Variables

## Observations

- ConfigMaps store configuration.

- Secrets store sensitive values.

- Applications consume external configuration.

- Volume mounts support configuration files.

## Results

Successfully managed application configuration using ConfigMaps and Secrets.

## Lessons Learned

- Never hardcode secrets.

- Separate configuration from code.

- Protect sensitive data.
