# Day 06 - ConfigMaps & Secrets

## Overview

This module covers Kubernetes ConfigMaps, Secrets, Environment Variables, Configuration Management, Secret Injection, Volume Mounts, and Production Configuration Strategies.

Applications require configuration such as:

- URLs

- Database Names

- Environment Settings

- API Keys

- Passwords

Kubernetes separates configuration from application code using ConfigMaps and Secrets.
