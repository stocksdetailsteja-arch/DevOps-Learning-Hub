# DevOps Learning Roadmap

## Purpose

This roadmap provides a structured path to learn DevOps from Beginner to Advanced level.

The goal is to understand concepts, perform hands-on labs, build projects, prepare for interviews, and become industry-ready.

==================================================

PHASE 1 - LINUX

Topics

- Linux Introduction
- Linux Architecture
- File System
- File Management
- Users and Groups
- Permissions
- Processes
- Networking
- Package Management
- Archiving
- System Administration

Outcome

- Understand Linux fundamentals
- Work comfortably in terminal
- Manage servers
