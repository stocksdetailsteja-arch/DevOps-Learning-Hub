# Day 06 - Lab Notes

## Objective

Learn Jenkins Pipeline creation and execution.

## Services Used

- Jenkins

- Jenkinsfile

- Pipeline

## Observations

- Pipelines provide automation as code.

- Jenkinsfile stores workflow definitions.

- Stages improve readability.

- Post actions improve operational visibility.

## Results

Successfully created and executed Jenkins Pipeline.

## Lessons Learned

- Use version-controlled Jenkinsfiles.

- Separate stages logically.

- Add post actions for notifications and cleanup.
