# Day 06 - Interview Questions

## Basic

### Q1 What Is A Jenkins Pipeline?

Automated workflow executed by Jenkins.

### Q2 What Is Pipeline As Code?

Pipeline definition stored inside source control.

### Q3 What Is Jenkinsfile?

File containing Jenkins pipeline definition.

### Q4 What Is A Stage?

Logical phase of a pipeline.

## Intermediate

### Q1 Difference Between Declarative And Scripted Pipeline?

Declarative:

Structured

Simple

Scripted:

Flexible

Groovy-Based

### Q2 Why Use Jenkinsfile?

Version control and repeatability.

### Q3 Why Use Parameters?

Reusable pipelines with dynamic input.

## Advanced (5+ Years)

### Q1 Why Are Pipelines Preferred Over Freestyle Jobs?

Answer:

- Version Control

- Auditability

- Reusability

- Scalability

- Infrastructure As Code Principles

### Q2 Pipeline Failed In Stage Build. What Will You Check?

Answer:

Console Output

Agent Logs

Environment Variables

Workspace

Tool Availability

### Q3 How Would You Design Enterprise Pipeline?

Answer:

SCM Checkout

Build

Test

Security Scan

Artifact Publish

Deploy

Validation

Notification

### Q4 Why Use Post Actions?

Answer:

- Notifications

- Cleanup

- Reporting

- Logging

### Q5 How Do You Secure Pipelines?

Answer:

- Credentials Store

- Parameter Validation

- RBAC

- Secret Masking

- Agent Isolation
