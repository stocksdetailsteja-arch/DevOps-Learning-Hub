# Day 01 - Jenkins Introduction

## Overview

This module introduces Jenkins, Continuous Integration, Continuous Delivery, Continuous Deployment, Jenkins terminology, Jenkins architecture, jobs, pipelines, plugins, controllers, agents, workspaces, executors, and common enterprise CI/CD workflows.

Jenkins is an open-source automation server used to automate activities related to building, testing, delivering, and deploying software.

## Learning Objectives

By the end of this module, you should be able to:

- Explain what Jenkins is

- Explain why Jenkins is used

- Explain Continuous Integration

- Explain Continuous Delivery

- Explain Continuous Deployment

- Differentiate Continuous Delivery from Continuous Deployment

- Understand the Jenkins controller

- Understand Jenkins agents

- Understand nodes and executors

- Understand Jenkins jobs

- Understand Jenkins workspaces

- Understand Jenkins plugins

- Understand Jenkins pipelines

- Explain Pipeline as Code

- Explain the purpose of a Jenkinsfile

- Describe an end-to-end Jenkins CI/CD flow

- Identify basic Jenkins security and operational risks

## Cost And Security Notice

If Jenkins is hosted on AWS EC2:

- Restrict inbound access

- Do not expose Jenkins unrestricted to the internet

- Stop or terminate unused lab instances

- Review attached EBS volumes

- Never store AWS access keys in Jenkinsfiles

- Never commit Jenkins credentials to GitHub

- Use least-privilege access

- Back up important Jenkins configuration before destructive changes
