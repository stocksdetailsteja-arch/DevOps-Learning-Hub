# Day 07 - GitHub Integration

## Overview

This module covers Jenkins GitHub Integration, Git Plugin, Credentials, Personal Access Token (PAT), Repository Configuration, Webhooks, Poll SCM, Automatic Builds, and Branch-Based Build Automation.

GitHub integration enables Jenkins to automatically build applications whenever code changes occur.
