# Day 07 - Interview Questions

## Basic

### Q1 Why Integrate GitHub With Jenkins?

Automate CI/CD activities.

### Q2 What Is SCM?

Source Code Management.

### Q3 What Is A Webhook?

Mechanism used to notify Jenkins about repository events.

### Q4 What Is A Personal Access Token?

Secure GitHub authentication mechanism.

## Intermediate

### Q1 Difference Between Webhook And Poll SCM?

Webhook:

Event Driven

Poll SCM:

Scheduled Checks

### Q2 Why Use Git Plugin?

Allows Jenkins to communicate with Git repositories.

### Q3 Why Use Credentials?

Secure access to source repositories.

## Advanced (5+ Years)

### Q1 Jenkins Cannot Clone Repository. What Will You Check?

Answer:

Credentials

Repository URL

Network Access

Git Plugin

Branch Configuration

### Q2 Why Are Webhooks Preferred?

Answer:

- Immediate Trigger

- Reduced Load

- Faster Feedback

- Efficient Automation

### Q3 Automatic Builds Not Triggering. What Will You Check?

Answer:

Webhook Configuration

Build Triggers

Repository Access

Jenkins Logs

### Q4 How Would You Secure GitHub Integration?

Answer:

- Use PAT

- Use Credentials Store

- Use RBAC

- Rotate Tokens

- Limit Repository Permissions

### Q5 How Do You Design Enterprise GitHub Integration?

Answer:

Multi-Branch Strategy

Secure Credentials

Webhooks

CI/CD Pipelines

Monitoring
