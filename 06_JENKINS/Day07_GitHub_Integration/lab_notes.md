# Day 07 - Lab Notes

## Objective

Integrate GitHub and Jenkins.

## Services Used

- Jenkins

- GitHub

- Git Plugin

- Webhooks

## Observations

- Jenkins can automatically retrieve source code.

- Webhooks trigger builds instantly.

- Credentials provide secure repository access.

## Results

Successfully integrated GitHub with Jenkins.

## Lessons Learned

- Secure credentials carefully.

- Validate repository access.

- Prefer webhooks over frequent polling when possible.
