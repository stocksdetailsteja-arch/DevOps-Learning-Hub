# Day 09 - CI/CD Project Troubleshooting

## Scenario 1

Checkout Failed

Cause:

Repository Access Problem

Resolution:

Review GitHub Configuration.

## Scenario 2

Build Failed

Cause:

Compilation Issue

Resolution:

Review Build Logs.

## Scenario 3

Tests Failed

Cause:

Application Defect

Resolution:

Review Test Reports.

## Scenario 4

Artifact Missing

Cause:

Packaging Failure

Resolution:

Review Build Output.

## Scenario 5 (5+ Years)

Deployment Failed

Investigation:

- Deployment Logs

- Credentials

- Infrastructure

Resolution:

Correct Deployment Configuration.

## Scenario 6 (5+ Years)

Validation Failed

Investigation:

- Application Logs

- Service Status

- Health Checks

Resolution:

Restore Service Or Rollback.

## Scenario 7 (5+ Years)

Rollback Required

Investigation:

- Deployment State

- Previous Build

Resolution:

Deploy Previous Stable Version.
