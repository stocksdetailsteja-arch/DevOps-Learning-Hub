# Day 09 - Interview Questions

## Basic

### Q1 What Is CI/CD?

Automated software delivery process.

### Q2 What Is Build Automation?

Automatic compilation and packaging of applications.

### Q3 Why Run Tests In Pipeline?

To detect issues before deployment.

### Q4 What Is Deployment Validation?

Verification that application works after deployment.

## Intermediate

### Q1 What Are Typical Pipeline Stages?

Checkout

Build

Test

Package

Deploy

Validate

### Q2 Why Generate Artifacts?

To create deployable application packages.

### Q3 Why Use Notifications?

To inform development and operations teams.

SCM Integration

### Q2 Build Passed But Deployment Failed. What Will You Check?

Answer:

Deployment Logs

Credentials

Environment Variables

Target Server

Health Checks

### Q3 Why Is Rollback Important?

Answer:

- Reduce Downtime

- Restore Service Quickly

- Minimize Production Impact

### Q4 How Do You Validate CI/CD Pipeline Reliability?

Answer:

- Pipeline Testing

- Build Monitoring

- Deployment Validation

- Recovery Drills

### Q5 Slow Pipeline Execution. How Do You Investigate?

Answer:

SCM Checkout Time

Build Duration

Test Duration

Agent Health

Infrastructure Performance
