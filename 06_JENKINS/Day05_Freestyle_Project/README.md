# Day 05 - Freestyle Project

## Overview

This module covers Jenkins Freestyle Projects, Source Code Management, Build Environment, Build Steps, Post Build Actions, Notifications, Workspace Management, and Real-World Automation Scenarios.

Freestyle Projects are the most commonly used Jenkins jobs for beginners and provide a graphical method of automating build and deployment tasks.
