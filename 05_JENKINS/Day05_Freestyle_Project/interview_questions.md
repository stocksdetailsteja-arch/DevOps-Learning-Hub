# Day 05 - Interview Questions

## Basic

### Q1 What Is A Freestyle Project?

GUI-based Jenkins job used for automation.

### Q2 What Is SCM?

Source Code Management system used for source retrieval.

### Q3 What Is A Build Step?

Task executed during job execution.

### Q4 What Is Build History?

Record of previous builds and statuses.

## Intermediate

### Q1 Difference Between Freestyle Project And Pipeline?

Freestyle:

GUI Configuration

Pipeline:

Code Configuration

### Q2 Why Use SCM?

Retrieve source code automatically.

### Q3 Why Use Post Build Actions?

Perform actions after successful build.

## Advanced (5+ Years)

### Q1 Build Succeeds But Artifact Missing. What Will You Check?

Answer:

Workspace

Build Commands

Archive Configuration

Output Paths

### Q2 Why Are Pipelines Preferred Over Freestyle Projects?

Answer:

- Version Control

- Reusability

- Scalability

- Better Governance

### Q3 Build Is Slow. What Will You Investigate?

Answer:

Build Steps

Agent Resources

Workspace Size

SCM Checkout Time

### Q4 Workspace Growing Continuously. What Will You Check?

Answer:

- Old Artifacts

- Cleanup Strategy

- Build Retention Policy

### Q5 How Would You Design Reusable Freestyle Jobs?

Answer:

- Parameters

- Shared Scripts

- Standardized Layout
