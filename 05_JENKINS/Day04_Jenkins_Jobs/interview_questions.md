# Day 04 - Interview Questions

## Basic

### Q1 What Is A Jenkins Job?

Configured task executed by Jenkins.

### Q2 What Is A Freestyle Job?

A GUI-based Jenkins job commonly used for automation.

### Q3 What Is Console Output?

Execution logs generated during build execution.

### Q4 What Is Workspace?

Location where Jenkins executes build activities.

## Intermediate

### Q1 What Are Build Triggers?

Mechanism used to start jobs automatically.

### Q2 What Are Build Steps?

Actual execution commands of a job.

### Q3 What Is A Parameterized Job?

Job that accepts user input before execution.

## Advanced (5+ Years)

### Q1 Build Is Failing. What Will You Check?

Answer:

Console Output

Workspace

Build Step

Environment Variables

Credentials

### Q2 How Would You Design Reusable Jobs?

Answer:

- Parameterization

- Common Scripts

- Standardized Configuration

### Q3 Why Is Workspace Cleanup Important?

Answer:

- Prevent Disk Issues

- Avoid Old Build Artifacts

- Improve Reliability

### Q4 Job Is Stuck In Queue. What Will You Check?

Answer:

Executors

Agent Availability

Labels

Queue Configuration

### Q5 How Do You Troubleshoot Intermittent Job Failures?

Answer:

- Review Logs

- Review Parameters

- Review Agent Utilization

- Check Workspace State
