 # Day 08 - Interview Questions

## Basic

### Q1 What Are Jenkins Credentials?

Securely stored authentication secrets.

### Q2 Why Use Credentials Store?

Protect sensitive information.

### Q3 What Is Secret Text?

Secure storage for tokens and keys.

### Q4 What Is An SSH Key Credential?

Credential used for secure SSH authentication.

## Intermediate

### Q1 Why Use PAT Instead Of Password?

Improved security and easier access control.

### Q2 What Is Credential Binding?

Injecting credentials securely during execution.

### Q3 What Is Secret Masking?

Hiding secrets from logs and console output.

## Advanced (5+ Years)

### Q1 How Would You Secure Jenkins Credentials?

Answer:

- Least Privilege

- Secret Rotation

- Credential Scope Control

- RBAC

- Audit Reviews

### Q2 Credentials Exposed In Logs. What Will You Do?

Answer:

Revoke Credential

Rotate Secret

Investigate Exposure

Review Build Logs

Update Security Controls

### Q3 Why Should Secrets Never Be Hardcoded?

Answer:

- Security Risk

- Source Code Exposure

- Compliance Issues

### Q4 How Would You Handle Enterprise Secret Management?

Answer:

Centralized Secret Store

Controlled Access

Auditing

Automatic Rotation

Environment Segregation

### Q5 Build Fails Due To Credential Error. What Will You Check?

Answer:

Credential ID

Scope

Expiration

Permissions

Pipeline Configuration
