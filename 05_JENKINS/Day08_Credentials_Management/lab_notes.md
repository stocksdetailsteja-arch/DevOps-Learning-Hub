# Day 08 - Lab Notes

## Objective

Learn Jenkins Credentials Management and secure authentication.

## Services Used

- Jenkins

- Credentials Store

- SSH Keys

- Tokens

## Observations

- Credentials improve security.

- Secret masking prevents accidental exposure.

- Credential IDs simplify administration.

## Results

Successfully configured and used Jenkins credentials.

## Lessons Learned

- Never hardcode secrets.

- Rotate credentials regularly.

- Review access controls.
