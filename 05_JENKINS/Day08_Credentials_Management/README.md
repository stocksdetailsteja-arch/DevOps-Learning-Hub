# Day 08 - Credentials Management

## Overview

This module covers Jenkins Credentials Management, Username & Password Credentials, Personal Access Tokens, Secret Text, SSH Keys, Credentials Binding, Secret Masking, and Security Best Practices.

Credentials Management is one of the most important security topics in Jenkins.
