# Day 03 - Lab Notes

## Objective

Understand Jenkins Architecture and execution flow.

## Services Used

- Jenkins Controller

- Built-In Node

- Executors

- Workspace

## Observations

- Controller manages jobs.

- Agents execute jobs.

- Executors determine concurrency.

- Workspace stores build data.

## Results

Successfully reviewed Jenkins Architecture.

## Lessons Learned

- Avoid heavy builds on controller.

- Use agents for scale.

- Plan executors carefully.
