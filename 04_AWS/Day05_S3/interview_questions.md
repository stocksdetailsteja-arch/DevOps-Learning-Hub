# Day 05 - Interview Questions

## Basic

### Q1 What Is S3?

AWS object storage service.

### Q2 What Is A Bucket?

Container used to store objects.

### Q3 What Is Versioning?

Maintains multiple versions of objects.

## Intermediate

### Q1 Difference Between S3 And EBS?

S3:

Object Storage

EBS:

Block Storage

### Q2 Why Use Lifecycle Policies?

Reduce storage costs automatically.

### Q3 Difference Between SSE-S3 And SSE-KMS?

SSE-S3:

AWS Managed

SSE-KMS:

Customer-controlled key management.

## Advanced (5+ Years)

### Q1 How Would You Store Terraform State Securely?

Answer:

S3 Bucket

Versioning Enabled

Encryption Enabled

Access Restricted

### Q2 Jenkins Artifacts Need Long-Term Storage. What Would You Use?

Answer:

S3 Bucket

Lifecycle Policy

Archive Storage

### Q3 How Do You Protect Against Accidental File Deletion?

Answer:

Enable Versioning

Enable Access Controls

Maintain Backups

### Q4 How Would You Optimize S3 Costs?

Answer:

- Lifecycle Policies

- Archive Old Data

- Remove Unused Objects

- Review Storage Classes

### Q5 Explain A Real DevOps Use Case For S3.

Answer:

Build Artifact Storage.

Jenkins uploads artifacts.

Deployment pipelines download artifacts.
