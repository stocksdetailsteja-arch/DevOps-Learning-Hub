# Day 05 - Amazon S3

## Overview

This module covers Amazon S3 (Simple Storage Service), Buckets, Objects, Storage Classes, Versioning, Lifecycle Policies, Static Website Hosting, Encryption, Access Control, and Cost Optimization.

Amazon S3 is AWS's object storage service used for storing and retrieving any amount of data.
