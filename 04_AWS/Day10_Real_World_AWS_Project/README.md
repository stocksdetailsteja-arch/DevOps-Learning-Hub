# Day 10 - Real World AWS Project

## Overview

This project builds a production-style AWS architecture using multiple AWS services.

Services Used:

- IAM

- EC2

- EBS

- S3

- VPC

- RDS

- ALB

- Auto Scaling

- CloudWatch

- SNS

The project simulates a real-world enterprise application deployment.

## Learning Objectives

- Design Production Architecture

- Implement High Availability

- Implement Scalability

- Implement Security

- Configure Monitoring

- Optimize Costs

- Practice Disaster Recovery
