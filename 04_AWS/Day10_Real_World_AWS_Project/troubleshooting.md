# Day 10 - Real World AWS Project Troubleshooting

## Scenario 1

Application Not Reachable

Investigation:

- ALB

- Target Group

- Security Groups

- Route Tables

Resolution:

Restore connectivity.

## Scenario 2

Database Connection Failure

Investigation:

- Security Groups

- Endpoint

- Credentials

- Application Config

Resolution:

Correct configuration.

## Scenario 3

Auto Scaling Not Launching Instances

Investigation:

- Launch Template

- Capacity Limits

- Policies

Resolution:

Correct ASG configuration.

## Scenario 4

Monitoring Alerts Missing

Investigation:

- Alarm Configuration

- SNS Subscription

Resolution:

Restore notification flow.

## Scenario 5 (5+ Years)

Production Outage

Investigation:

- CloudWatch Metrics

- Load Balancer Health

- Database Status

- Infrastructure Events

Resolution:

Recover service and perform RCA.

## Scenario 6 (5+ Years)

Unexpected AWS Bill

Investigation:

- NAT Gateway

- RDS

- EC2

- Snapshots

- Load Balancer

Resolution:

Review architecture and resource usage.

## Scenario 7 (5+ Years)

Disaster Recovery Validation Failed

Investigation:

- Backup Integrity

- Recovery Runbook

- Recovery Testing

Resolution:

Update DR process and retest.
