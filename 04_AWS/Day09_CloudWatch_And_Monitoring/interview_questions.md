# Day 09 - Interview Questions

## Basic

### Q1 What Is CloudWatch?

AWS monitoring service.

### Q2 What Is A Metric?

Measurement collected over time.

### Q3 What Is SNS?

Notification service used for messaging and alerts.

### Q4 What Is CloudTrail?

AWS audit and activity tracking service.

Answer:

### Q3 What Should Trigger Critical Alerts?

Answer:

- Application Down

- High Error Rate

- Database Availability Issues

- Infrastructure Failures

- Security Events

### Q4 Monitoring Produces Too Many Alerts. How Do You Fix Alert Fatigue?

Answer:

- Improve Thresholds

- Reduce Noise

- Add Severity Levels

- Group Similar Alerts

- Focus On Actionable Events

### Q5 What Evidence Do You Collect During Production Incidents?

Answer:

- Metrics

- Logs

- Dashboards

- Alert Timeline

- Deployment History

- Infrastructure Status
