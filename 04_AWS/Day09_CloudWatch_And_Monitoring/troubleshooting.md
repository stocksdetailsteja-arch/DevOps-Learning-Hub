# Day 09 - CloudWatch And Monitoring Troubleshooting

## Scenario 1

CloudWatch Metric Missing

Cause:

Service Not Publishing Metrics

Resolution:

Verify Service Configuration

## Scenario 2

Alarm Not Triggering

Cause:

Threshold Incorrect

Resolution:

Review Alarm Configuration

## Scenario 3

SNS Email Not Received

Cause:

Subscription Not Confirmed

Resolution:

Confirm Email Subscription

## Scenario 4

Logs Not Appearing

Cause:

Logging Configuration Issue

Resolution:

Verify Log Configuration

## Scenario 5 (5+ Years)

Production Outage Not Detected

Investigation:

- Monitoring Coverage

- Alarm Configuration

- Dashboard Visibility

- Notification Routing

Resolution:

Improve Monitoring Strategy

## Scenario 6 (5+ Years)

CloudTrail Shows Unauthorized Action

Investigation:

- Event History

- User Identity

- IAM Permissions

- Resource Impact

Resolution:

Follow Security Investigation Process

## Scenario 7 (5+ Years)

High CloudWatch Costs

Investigation:

- Excessive Logs

- High Retention

- Unused Dashboards

- Excessive Metrics

Resolution:

Optimize Retention And Collection Strategy
