# Day 09 - CloudWatch And Monitoring

## Overview

This module covers Amazon CloudWatch, CloudWatch Metrics, Logs, Alarms, Dashboards, SNS Notifications, CloudTrail, Monitoring Strategy, Alerting, Operational Visibility, Incident Detection, and Production Monitoring Architecture.

Monitoring helps identify issues quickly and supports faster recovery.
