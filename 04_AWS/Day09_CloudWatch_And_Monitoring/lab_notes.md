# Day 09 - Lab Notes

## Objective

Learn AWS monitoring and alerting.

## Services Used

- CloudWatch

- SNS

- CloudTrail

## Observations

- Metrics provide visibility.

- Alarms provide proactive monitoring.

- SNS delivers notifications.

- CloudTrail supports auditing.

## Results

Successfully implemented monitoring and alerting.

## Lessons Learned

- Monitoring should be proactive.

- Alerts should be meaningful.

- Monitor business-critical services.
