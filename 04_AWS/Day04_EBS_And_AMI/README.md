# Day 04 - EBS And AMI

## Overview

This module covers Amazon EBS (Elastic Block Store), EBS Volume Types, Snapshots, Amazon Machine Images (AMI), Backup Strategies, Disaster Recovery, Volume Expansion, and Production Recovery Techniques.

EBS provides persistent block storage for EC2 instances.

AMIs allow rapid deployment of standardized servers.

## Cost Awareness

Important:

Stopped instances may stop compute charges, but EBS volumes and snapshots can still incur storage charges.

Always clean up unused volumes and snapshots.
