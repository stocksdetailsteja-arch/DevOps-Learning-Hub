# Day 03 - EC2 Lab Notes

## Objective

Learn EC2 deployment and management.

## Components Used

- EC2

- Security Groups

- Key Pair

- Ubuntu

- NGINX

## Observations

- EC2 is easy to provision.

- Security Groups act as firewall.

- Key Pairs secure login access.

## Results

Successfully launched and accessed EC2 server.

## Lessons Learned

- Never expose SSH publicly without restriction.

- Cleanup resources after labs.

- Use proper instance sizing.
