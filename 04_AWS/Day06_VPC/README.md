# Day 06 - Amazon VPC

## Overview

This module covers Amazon Virtual Private Cloud (VPC), CIDR Blocks, Public and Private Subnets, Route Tables, Internet Gateway, NAT Gateway, Security Groups, Network ACLs, and Production Network Design.

VPC is the networking foundation of AWS.

- Understand VPC Architecture

- Create VPCs

- Create Subnets

- Configure Route Tables

- Configure Internet Access

- Configure Private Networking

- Understand NAT Gateway

- Design Production Networks
