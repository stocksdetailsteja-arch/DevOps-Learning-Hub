# Day 06 - Lab Notes

## Objective

Learn AWS Networking and VPC Design.

## Services Used

- VPC

- Subnets

- Route Tables

- Internet Gateway

- Security Groups

- NACL

## Observations

- VPC provides isolation.

- Public and Private Subnets serve different purposes.

- Security Groups and NACLs provide layered security.

## Results

Successfully created a basic production-style VPC architecture.

## Lessons Learned

- Design subnets carefully.

- Use private subnets for backend services.

- Avoid exposing databases publicly.
