# Day 08 - Load Balancer And Auto Scaling

## Overview

This module covers Elastic Load Balancing (ELB), Application Load Balancers (ALB), Target Groups, Health Checks, Auto Scaling Groups (ASG), Launch Templates, Scaling Policies, High Availability, and Production Architecture Design.

Load balancing distributes traffic across multiple servers.

Auto Scaling automatically adjusts infrastructure based on demand.
