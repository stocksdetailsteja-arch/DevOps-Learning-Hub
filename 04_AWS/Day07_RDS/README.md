# Day 07 - Amazon RDS

## Overview

This module covers Amazon RDS (Relational Database Service), Database Engines, Multi-AZ Deployments, Read Replicas, Backups, Snapshots, Monitoring, Failover, and Production Database Architecture.

RDS simplifies database administration by automating backups, patching, monitoring, and failover operations.
