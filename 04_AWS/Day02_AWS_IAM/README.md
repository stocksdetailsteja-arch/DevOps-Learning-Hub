# Day 02 - AWS IAM

## Overview

This module covers AWS Identity and Access Management (IAM), including Users, Groups, Roles, Policies, MFA, Least Privilege, Permission Management, and Enterprise IAM Security Practices.

IAM is the foundation of AWS security.

## Learning Objectives

- Understand IAM

- Create IAM Users

- Create IAM Groups

- Create IAM Roles

- Understand IAM Policies

- Enable MFA

- Apply Least Privilege

- Secure AWS Accounts

## Cost Impact

IAM itself generally does not create compute resources.

However:

- Incorrect permissions can create expensive resources.

- Administrator privileges should be granted carefully.
