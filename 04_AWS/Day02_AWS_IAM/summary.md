# Day 02 - Summary

## Topics Covered

- IAM Users

- IAM Groups

- IAM Roles

- IAM Policies

- MFA

- Least Privilege

## Commands Learned

- aws iam list-users

- aws iam create-user

- aws iam create-group

- aws iam add-user-to-group

- aws iam list-policies

## Quick Revision

User → Person/Application

Group → Collection Of Users

Role → Temporary Credentials

Policy → Permission Definition

MFA → Additional Security Layer

Least Privilege → Minimum Access Required

## Production Notes

- Never use root daily

- Enable MFA

- Prefer Roles over Access Keys

- Use Least Privilege

- Audit Permissions Regularly

## Key Takeaways

- IAM is the foundation of AWS security.

- Roles are preferred for workloads.

- Policies define permissions.

- Security begins with identity control.
