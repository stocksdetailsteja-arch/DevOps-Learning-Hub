# Day 02 - AWS IAM Lab Notes

## Objective

Learn AWS Identity and Access Management fundamentals.

## Commands Executed

- aws iam list-users

- aws iam create-user

- aws iam create-group

- aws iam add-user-to-group

- aws iam list-policies

## Observations

- IAM controls AWS access.

- Groups simplify permission assignment.

- Roles reduce secret management.

- MFA improves security.

## Results

Successfully implemented IAM identities and permissions.

## Lessons Learned

- Avoid root account.

- Use roles whenever possible.

- Apply least privilege.

- Enable MFA.
