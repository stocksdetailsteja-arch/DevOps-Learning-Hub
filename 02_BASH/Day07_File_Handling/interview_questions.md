# Day 07 - Interview Questions

## Basic

### Q1 What Is File Handling?

Reading, writing, and processing files using scripts.

### Q2 Difference Between > and >> ?

>

Overwrite file.

>>

Append file.

## Intermediate

### Q1 How Do You Check If A File Exists?

Answer:

-f

### Q2 How Do You Check If A File Is Empty?

Answer:

-s

## Advanced (5+ Years)

### Q1 Why Is File Validation Critical In DevOps?

Answer:

Prevents:

- Failed Deployments

- Missing Configurations

- Application Failures

### Q2 How Would You Process 1000 Servers From A File?

Answer:

Read file line by line.

Loop through entries.

Capture success and failure.

Generate execution report.

### Q3 Explain Log Processing Automation.

Answer:

Automation reads log files.

Identifies patterns.

Generates reports.

Creates alerts.

### Q4 What Problems Occur When File Handling Is Poor?

Answer:

- Data Loss

- Corrupt Configurations

- Invalid Deployments

- Missing Logs
