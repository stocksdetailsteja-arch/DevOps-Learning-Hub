# Day 07 - Troubleshooting

## Scenario 1

File Not Found

Error:

No such file

Cause:

Incorrect path.

Resolution:

Validate path.

## Scenario 2

Permission Denied

Cause:

Insufficient permissions.

Resolution:

Verify ownership and permissions.

## Scenario 3

File Empty

Cause:

Data generation failed.

Resolution:

Validate source process.

## Scenario 4

Log Processing Fails

Cause:

Invalid file format.

Resolution:

Validate input.

## Scenario 5 (5+ Years)

Inventory Processing Misses Servers

Investigation:

- Validate File

- Validate Reading Logic

- Review Loop

- Review Logging

Resolution:

Correct file parsing logic.

## Scenario 6 (5+ Years)

Configuration Update Script Corrupted Production Config

Investigation:

- Review Backup

- Review Script Logic

- Review File Permissions

Resolution:

Restore backup and fix script.
