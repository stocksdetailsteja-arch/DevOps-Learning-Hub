# Day 04 - Interview Questions

## Basic

### Q1 What is a Loop?

A Loop repeatedly executes a block of code until a condition is met.

### Q2 Difference between For Loop and While Loop?

For Loop:

Known iterations.

While Loop:

Unknown iterations based on condition.

## Intermediate

### Q1 What is Break?

Break immediately exits a loop.

### Q2 What is Continue?

Continue skips the current iteration and proceeds to the next iteration.

## Advanced (5+ Years)

### Q1 Why are loops important in DevOps?

Answer:

Loops enable automation of repetitive tasks:

- Server checks

- User creation

- Deployments

- Monitoring

- Scaling operations

### Q2 How would you deploy to 100 servers using Bash?

Answer:

Use a server list and for loop:

for SERVER in servers

do

Deploy

done

Validate success and capture failures.

### Q3 How do you avoid infinite loops?

Answer:

Proper exit condition

Validation

Timeout Logic

Monitoring

### Q4 Explain a real-world monitoring use case.

Answer:

Loop through services:

ssh

docker

jenkins

Check service status.

Generate alerts for failures.
