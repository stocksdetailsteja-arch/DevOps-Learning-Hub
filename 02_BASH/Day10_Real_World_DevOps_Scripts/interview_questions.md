# Day 10 - Interview Questions

## Basic

### Q1 Why automate administration tasks?

Answer:

Automation reduces manual effort and errors.

### Q2 What tasks are commonly automated using Bash?

Answer:

- Monitoring

- Backups

- Deployments

- Reporting

## Intermediate

### Q1 What should every production script include?

Answer:

- Validation

- Logging

- Error Handling

- Recovery Logic

### Q2 Why is logging mandatory?

Answer:

Provides troubleshooting information and audit history.

## Advanced (5+ Years)

### Q1 Design a disk monitoring solution.

Answer:

Check disk usage.

Compare with threshold.

Generate alert.

Log event.

Notify administrator.

### Q2 How would you automate deployment validation?

Answer:

Validate:

- Artifact

- Configuration

- Environment

- Services

Proceed only when all validations succeed.

### Q3 Explain health-check automation.

Answer:

Monitor:

- CPU

- Memory

- Disk

- Services

Generate reports and alerts.

### Q4 Which Bash skills are used most in DevOps?

Answer:

- Variables

- Loops

- Functions

- Arrays

- File Handling

- Error Handling

- Logging
