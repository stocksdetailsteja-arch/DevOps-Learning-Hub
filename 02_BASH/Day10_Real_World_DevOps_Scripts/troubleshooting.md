# Day 10 - Troubleshooting

## Scenario 1

Backup Script Failed

Investigation:

- Check Source Files

- Check Disk Space

- Review Logs

Resolution:

Fix source issue and rerun.

## Scenario 2

Disk Monitoring Shows Wrong Usage

Cause:

Incorrect parsing.

Resolution:

Validate awk and sed logic.

## Scenario 3

Service Monitoring Reports False Failure

Cause:

Wrong service name.

Resolution:

Verify service status manually.

## Scenario 4

Log Cleanup Removed Wrong Files

Cause:

Incorrect find command.

Resolution:

Test command before deletion.

## Scenario 5 (5+ Years)

Production Deployment Failed

Investigation:

- Logs

- Environment

- Artifact

- Service Health

- Network

Resolution:

Rollback and perform RCA.

## Scenario 6 (5+ Years)

Monitoring Script Missed Critical Alert

Cause:

Validation Logic Missing.

Resolution:

Add thresholds and notification mechanism.
