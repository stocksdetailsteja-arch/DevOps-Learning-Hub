# Day 06 - Interview Questions

## Basic

### Q1 What is an Array?

A collection of multiple values stored under one variable.

### Q2 How do you access the first element?

${ARRAY[0]}

## Intermediate

### Q1 Difference Between Array And Variable?

Variable:

Stores one value.

Array:

Stores multiple values.

### Q2 How do you get array length?

${#ARRAY[@]}

## Advanced (5+ Years)

### Q1 Why are arrays important in DevOps?

Answer:

Arrays help manage:

- Servers

- Applications

- Environments

- Resources

in scalable automation.

### Q2 How would you deploy to multiple servers?

Answer:

Store servers in array.

Loop through array.

Execute deployment.

Capture success and failures.

### Q3 Explain associative arrays in production.

Answer:

Useful for:

Environment → IP

Application → Version

Service → Port

Mappings.

Example:

DEV → 10.0.0.10

PROD → 10.0.0.20

### Q4 What problems occur when arrays are mishandled?

Answer:

- Missing elements

- Incorrect indexing

- Deployment failures

- Skipped targets

- Invalid iterations
