# Day 05 - Functions

## Overview

This module covers Bash Functions, Function Parameters, Return Values, Reusable Code, Modular Scripting, and Production Script Design.

Functions help break large scripts into smaller reusable blocks, making automation easier to maintain and troubleshoot.

## Learning Objectives

- Understand Functions

- Create Functions

- Call Functions

- Pass Arguments To Functions

- Return Values

- Use Local Variables

- Build Modular Scripts

- Create Reusable Automation Logic

## Topics Covered

- Function Basics

- Function Declaration

- Function Invocation

- Function Arguments

- Return Values

- Local Variables

- Global Variables

- Function Libraries

- Script Modularity

## DevOps Relevance

Functions are used in:

- Deployment Scripts

- Monitoring Scripts

- Backup Automation

- Jenkins Pipelines

- AWS Automation

- Kubernetes Scripts

- Health Check Scripts
