# Day 05 - Interview Questions

## Basic

### Q1 What is a Function?

A reusable block of code that performs a specific task.

### Q2 Why use Functions?

To avoid code duplication.

## Intermediate

### Q1 Difference Between Local And Global Variables?

Local:

Available only inside function.

Global:

Available throughout script.

### Q2 How Are Parameters Passed To Functions?

Using positional arguments.

Example:

function_name value1 value2

## Advanced (5+ Years)

### Q1 Why Are Functions Important In DevOps?

Answer:

Functions make scripts:

- Modular

- Reusable

- Maintainable

- Easier To Test

### Q2 How Do You Structure Large Production Scripts?

Answer:

Separate:

- Validation Functions

- Logging Functions

- Deployment Functions

- Health Check Functions

- Rollback Functions

### Q3 How Would You Build A Deployment Framework In Bash?

Answer:

Functions:

- validate_input()

- deploy_application()

- verify_deployment()

- rollback_deployment()

- notify_team()

### Q4 What Is The Most Common Problem In Large Bash Scripts?

Answer:

Poor Modularity.

Functions help reduce complexity.
