# Day 01 - Bash Concepts

## What Is Bash?

Bash stands for:

Bourne Again Shell

Bash is a command-line interpreter used to interact with Linux.

Bash accepts commands from users and executes them.

## What Is A Shell?

A shell is an interface between:

User

↓

Shell

↓

Kernel

↓

Hardware

It accepts commands and passes them to the operating system.

## Types Of Shells

Common Linux Shells:

- Bash

- Sh

- Ksh

- Csh

- Zsh

Most Linux distributions use Bash by default.

## Why Bash Is Important?

Benefits:

- Automation

- Repeatability

- Reduced Manual Work

- Faster Operations

- Production Management

## What Is A Bash Script?

A Bash script is a file containing Linux commands.

Example:

backup.sh

monitor.sh

cleanup.sh

## What Is Shebang?

A shebang tells Linux which interpreter should execute the script.

Example:

#!/bin/bash

This is usually the first line in a Bash script.

## Bash Execution Flow

Script

↓

Bash Interpreter

↓

Linux Kernel

↓

System Calls

↓

Output
