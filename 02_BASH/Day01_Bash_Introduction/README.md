# Day 01 - Bash Introduction

## Overview

This module introduces Bash (Bourne Again Shell), shell scripting fundamentals, script execution, and automation basics.

Bash is the most widely used shell in Linux and forms the foundation of Linux automation and DevOps scripting.

## Learning Objectives

- Understand Bash

- Understand Shell

- Create Bash Scripts

- Execute Bash Scripts

- Understand Script Structure

- Learn Automation Basics

## Topics Covered

- What Is Bash?

- What Is Shell?

- Types Of Shells

- Bash Script Structure

- Executing Scripts

- Shebang

- Script Permissions

- Basic Automation

## Why Learn Bash?

Bash helps automate:

- Linux Administration

- CI/CD Tasks

- Monitoring

- Backup Jobs

- Log Management

- Cron Jobs

## DevOps Relevance

Bash is heavily used in:

- Jenkins

- Docker

- Kubernetes

- Terraform Automation

- EC2 Administration

- Monitoring
