# Day 07 - AWS Infrastructure

## Overview

This module covers AWS Infrastructure provisioning using Terraform, including VPCs, EC2 Instances, Security Groups, IAM, S3 Buckets, and Infrastructure Automation.

Terraform enables AWS infrastructure to be provisioned using code, making deployments repeatable, consistent, reviewable, and automated. Terraform Day 7 focuses on AWS infrastructure provisioning concepts and labs.

- Understand AWS Infrastructure Provisioning

- Create EC2 Instances

- Create VPCs

- Configure Security Groups

- Automate Infrastructure Deployment
