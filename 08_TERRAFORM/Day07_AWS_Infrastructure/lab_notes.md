# Day 07 - Lab Notes

## Objective

Provision AWS Infrastructure using Terraform.

## Services Used

- VPC

- EC2

- Security Group

- IAM

- S3

## Observations

- Terraform automates AWS deployments.

- Infrastructure becomes repeatable.

- Infrastructure should be defined as code.

- Use version control for infrastructure.

- Infrastructure becomes easier to manage.
