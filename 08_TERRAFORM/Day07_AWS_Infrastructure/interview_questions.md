# Day 07 - Interview Questions

## Basic

### Q1 What Is A VPC?

Virtual Private Cloud providing isolated AWS networking.

### Q2 What Is EC2?

AWS virtual machine service.

### Q3 What Is A Security Group?

Virtual firewall controlling inbound and outbound traffic.

### Q4 What Is S3?

AWS object storage service.

## Intermediate

### Q1 Why Provision AWS Using Terraform?

Improves automation, consistency, and repeatability.

### Q2 What Is An Internet Gateway?

Provides internet access to resources inside a VPC.

### Q3 Why Use IAM?

Controls identity and access permissions.

## Advanced (5+ Years)

### Q1 Terraform Apply Failed During EC2 Creation. What Will You Check?

Answer:

IAM Permissions

AWS Region

AMI ID

Quotas

Provider Configuration

### Q2 How Would You Design Production AWS Infrastructure?

Answer:

- VPC

- Public And Private Subnets

- Multiple Availability Zones

- Security Groups

- IAM Roles

- Load Balancer

- Monitoring

### Q3 Why Use Terraform Instead Of Cloud Console?

Answer:

- Automation

- Version Control

- Repeatability

- Faster Provisioning

### Q4 Why Use Private Subnets For Applications?

Answer:

Improves security by avoiding direct internet exposure.

### Q5 How Does Terraform Help DevOps Teams?

Answer:

Infrastructure becomes auditable, consistent, reusable, and automated.
