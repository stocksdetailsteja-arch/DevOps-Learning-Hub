# Day 06 - Terraform Backends

## Overview

This module covers Terraform Backends, Remote State, S3 Backends, DynamoDB Locking, Team Collaboration, State Security, and Enterprise State Management.

Backends determine where Terraform state is stored and how it is managed.

Remote backends enable teams to collaborate safely by storing state centrally instead of locally. Day 6 focuses on S3 backend and locking concepts.

- Configure S3 Backend
