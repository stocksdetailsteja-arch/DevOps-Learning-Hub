# Day 09 - Terraform Project

## Overview

This module combines all Terraform concepts learned so far into a complete AWS Infrastructure Project.

The project will provision:

- VPC

- Subnets

- Internet Gateway

- Route Tables

- Security Groups

- EC2 Instance

- S3 Bucket

- Remote Backend

- Outputs

- Modules

This project represents a real-world Infrastructure as Code implementation using Terraform.

## Learning Objectives

- Build End-To-End Infrastructure

- Use Modules

- Deploy AWS Infrastructure

- Validate Infrastructure

- Apply Best Practices

- Understand Project Design

- Prepare For Production Infrastructure
