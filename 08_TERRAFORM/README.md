# Terraform for DevOps

## Overview

Terraform is an Infrastructure as Code (IaC) tool used to provision, manage, and automate cloud infrastructure using declarative configuration files.

Instead of manually creating infrastructure through cloud consoles, Terraform allows engineers to define, deploy, modify, and destroy infrastructure through code.

Terraform supports multiple cloud providers including:

- AWS

- Azure

- Google Cloud Platform

- Kubernetes

- VMware

- Oracle Cloud

## What Is Infrastructure As Code (IaC)?

Infrastructure As Code means managing infrastructure using code instead of manual operations.

Traditional Method:

Login To Console

↓

Create Resource

↓

Configure Resource

↓

Repeat

IaC Method:

Write Terraform Code

↓

terraform apply

↓

Infrastructure Created

Benefits:

- Automation

- Repeatability

- Consistency

- Version Control

- Faster Deployments
