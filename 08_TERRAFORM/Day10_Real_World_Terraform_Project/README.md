# Day 10 - Real World Terraform Project

## Overview

This module implements a production-style AWS Infrastructure Project using Terraform.

The objective is to create a real-world enterprise infrastructure deployment using:

- VPC

- Public Subnets

- Private Subnets

- Internet Gateway

- NAT Gateway

- Security Groups

- IAM

- EC2

- Load Balancer

- S3 Backend

- DynamoDB Locking

- Reusable Modules

- CI/CD Integration

This project combines all Terraform concepts learned throughout the Terraform module.
