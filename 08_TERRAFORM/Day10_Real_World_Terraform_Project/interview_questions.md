# Day 10 - Interview Questions

## Basic

### Q1 What Is A Production Terraform Project?

Terraform implementation that follows enterprise standards, security, automation, and scalability practices.

### Q2 Why Use Modules?

To improve reusability and maintainability.

### Q3 Why Use Remote State?

To support collaboration and state protection.

## Intermediate

### Q1 Why Separate Dev, QA, And Prod?

To isolate environments and reduce deployment risk.

### Q2 Why Use S3 And DynamoDB Together?

S3 stores state.

DynamoDB provides state locking.

### Q3 Why Integrate Terraform Into CI/CD?

To automate validation and deployments.

## Advanced (5+ Years)

### Q1 How Would You Design Enterprise Terraform Infrastructure?

Answer:

- Modular Design

- Environment Separation

- Remote State

- CI/CD

- Security Controls

### Q2 Why Is State Protection Critical?

Answer:

State is the source of truth for managed infrastructure.

### Q3 Production Infrastructure Drift Detected. What Will You Check?

Answer:

Terraform State

AWS Resources

Recent Changes

Configuration

Backend

### Q4 How Would You Secure Terraform Deployments?

Answer:

- IAM Roles

- Encryption

- Remote State

- Restricted Access

- Secure Pipelines

### Q5 What Makes Infrastructure Enterprise Ready?

Answer:

- Automation

- Security

- Governance

- Documentation

- Reusability
