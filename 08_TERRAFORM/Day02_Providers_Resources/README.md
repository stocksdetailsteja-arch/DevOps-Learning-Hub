# Day 02 - Providers & Resources

## Overview

This module covers Terraform Providers, Resources, Resource Blocks, Provider Configuration, AWS Provider, Dependency Graph, and Infrastructure Deployment.

Providers allow Terraform to communicate with cloud providers, while resources define the infrastructure that Terraform should create.
