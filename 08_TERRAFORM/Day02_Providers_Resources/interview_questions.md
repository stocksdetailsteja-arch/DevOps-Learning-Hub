# Day 02 - Interview Questions

## Basic

### Q1 What Is A Provider?

Plugin used by Terraform to communicate with cloud platforms.

### Q2 What Is A Resource?

Infrastructure component managed by Terraform.

### Q3 What Does terraform plan Do?

Shows infrastructure changes before execution.

### Q4 What Does terraform apply Do?

Creates or updates infrastructure.

## Intermediate

### Q1 Why Use terraform plan Before apply?

To review infrastructure modifications.

### Q2 What Is Dependency Graph?

Terraform's mechanism for determining resource creation order.

### Q3 What Is Resource Lifecycle?

Create

Update

Delete
