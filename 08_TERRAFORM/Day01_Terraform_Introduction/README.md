# Day 01 - Terraform Introduction

## Overview

This module introduces Terraform fundamentals, Infrastructure as Code (IaC), Terraform Architecture, Terraform Workflow, Terraform Lifecycle, and Infrastructure Automation.

Terraform is an Infrastructure as Code tool used to provision, manage, and automate cloud infrastructure through code.

Terraform enables engineers to create infrastructure using configuration files instead of manually creating resources through cloud consoles. Terraform follows a declarative model and workflow.
