# Day 01 - Interview Questions

## Basic

### Q1 What Is Terraform?

Terraform is an Infrastructure as Code tool used to provision and manage infrastructure through code.

### Q2 What Is Infrastructure As Code?

Managing infrastructure using code instead of manual operations.

### Q3 What Is terraform init?

Initializes the working directory and downloads required providers.

### Q4 What Is A Provider?

Plugin used to communicate with cloud platforms.

## Intermediate

### Q1 Why Is Terraform Declarative?

You define desired infrastructure and Terraform determines how to create it.

### Q2 What Is Terraform Core?

Responsible for plan creation, state management, and lifecycle operations.

### Q3 Why Use Infrastructure As Code?

Automation, consistency, auditing, and repeatability.

### Q4 What Is Idempotency?

Answer:

Running Terraform repeatedly should result in the same desired infrastructure state.

### Q5 Why Is Terraform Important For AWS?

Answer:

Terraform automates AWS infrastructure provisioning using reusable code.
