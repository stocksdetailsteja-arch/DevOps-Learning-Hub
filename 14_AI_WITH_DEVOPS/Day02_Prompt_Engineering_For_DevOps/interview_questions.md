# Prompt Engineering Interview Questions

## What Is Prompt Engineering?

Designing instructions that improve AI output quality.

## Why Is Prompt Engineering Important?

Better prompts produce more accurate and useful responses.

## What Is Role-Based Prompting?

Providing AI with a role.

Example:

Act as a Senior DevOps Engineer.

## What Is Zero-Shot Prompting?

Providing a task without examples.

## What Is Few-Shot Prompting?

Providing examples before the actual task.

## What Is Chain Of Thought Prompting?

Asking AI to explain reasoning step by step.

## How Does Prompt Engineering Help DevOps?

- Infrastructure Generation
- Documentation
- Troubleshooting
- Monitoring
- Automation

## How Do You Prevent Hallucination?

- Add Context
- Add Constraints
- Request Validation Steps
- Perform Manual Review
