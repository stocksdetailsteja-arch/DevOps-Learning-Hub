# Capstone Interview Questions

## Explain Your AI DevOps Project

Answer:

Built an AI Assisted DevOps Command Center that helps engineers:

- Analyze Logs
- Generate RCA Drafts
- Review Infrastructure
- Troubleshoot Kubernetes
- Analyze CI/CD Failures

while maintaining human approval and governance.

## What Problem Does It Solve?

Reduces investigation and documentation effort.

## How Is Security Handled?

- No secrets submitted
- Evidence sanitization
- Human approval controls

## How Is AI Validated?

- Evidence review
- Manual verification
- Validation commands
- Recovery confirmation

## What Are The Main Features?

- Log Analyzer
- RCA Generator
- K8s Troubleshooter
- Terraform Reviewer
- CI/CD Analyzer
- Runbook Generator

## Can It Modify Production?

No.

Production actions require human approval.

## Biggest Limitation?

AI can generate incorrect hypotheses.

Human validation remains mandatory.

## Biggest Benefit?

Faster operational analysis and documentation.

- API Integration
- Metrics Collection

- Workflow Automation
