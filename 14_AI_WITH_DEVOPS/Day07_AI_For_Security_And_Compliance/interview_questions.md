# AI Security And Compliance Interview Questions

## How Can AI Help Security?

- Configuration Reviews
- Policy Reviews
- Security Documentation
- Log Analysis

## Can AI Replace Security Engineers?

No.

AI assists analysis but security decisions require human validation.

## How Can AI Help IAM Reviews?

Identify:

- Excessive Permissions
- Wildcards
- Risky Access

## How Can AI Help Terraform Security?

Review:

- IAM
- Security Groups
- Encryption
- Public Access

The Terraform workbook promotes least-privilege access and policy controls. 【4-969167】

## What Is The Biggest Security Risk Of AI?

Following recommendations without validation.

## How Can AI Help Kubernetes Security?

Review:

- RBAC
- Secrets
- Service Accounts
- Network Policies

## What Should Never Be Shared With Public AI?

- Secrets
- Credentials
- Customer Data
- Sensitive Logs

The AI workbook specifically advises sanitizing sensitive information before using AI systems. 【2-6646ee】【1-0904eb】

## How Do You Validate AI Security Findings?

- Manual Review
- Testing
- Security Scanning
- Compliance Verification

## What Is Compliance?

Ensuring systems meet defined security and regulatory requirements.

## Explain DevSecOps

Security integrated throughout the software delivery lifecycle.
