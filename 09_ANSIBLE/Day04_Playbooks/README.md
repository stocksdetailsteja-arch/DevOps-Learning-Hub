# Day 04 - Ansible Playbooks

## Objective

Learn how to automate server configuration using Ansible Playbooks.

Playbooks are YAML files that contain a sequence of tasks executed on managed nodes.

In this module you will learn:

- What is a Playbook
- YAML syntax
- Tasks
- Variables
- Handlers
- Tags
- Multiple Plays
- Playbook execution
- Real-world DevOps automation

## Why Playbooks?

Ad-Hoc commands are useful for quick operations but are not reusable.

Playbooks provide:

- Automation
- Reusability
- Version Control
- Consistency
- Infrastructure as Code

## Real World Use Cases

- Install Nginx on 100 servers
- Configure Apache
- Create users
- Deploy applications
- Restart services automatically
- Configure security policies
- Build complete environments

## Expected Outcome

By the end of this lesson you will be able to:

- Create YAML playbooks
- Execute playbooks
- Use variables
- Create handlers
- Automate server provisioning
