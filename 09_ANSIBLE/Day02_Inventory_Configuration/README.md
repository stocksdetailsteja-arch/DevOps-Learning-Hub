# Day 02 - Inventory Configuration

## Overview

This module covers Ansible Inventory, Static Inventory, Dynamic Inventory, Host Groups, Inventory Variables, Group Variables, Host Variables, and Enterprise Inventory Design.

Inventories are the foundation of Ansible automation because they define which servers Ansible manages.
