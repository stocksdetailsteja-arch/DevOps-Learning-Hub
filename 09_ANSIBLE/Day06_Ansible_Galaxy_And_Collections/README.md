# Day 06 - Ansible Galaxy And Collections

## Objective

Learn how to use Ansible Galaxy and Collections to reuse community-developed automation components and accelerate infrastructure deployment.

Ansible Galaxy is the official repository for Roles and Collections.

In this module you will learn:

- What is Ansible Galaxy
- What are Collections
- Installing Roles
- Installing Collections
- Managing Dependencies
- Reusing Community Content
- Best Practices
- Enterprise Usage

## Why Ansible Galaxy?

Without Galaxy:

- Build everything from scratch
- Increased development effort
- Difficult standardization

With Galaxy:

- Faster deployments
- Reusable automation
- Community support
- Enterprise scalability

## Real World Use Cases

- AWS infrastructure automation
- Kubernetes deployments
- Docker management
- Linux server provisioning
- Security hardening
- Database deployment

## Expected Outcome

By the end of this lesson you will be able to:

- Install Roles from Galaxy
- Use Collections
- Manage external dependencies
- Implement enterprise-grade automation
