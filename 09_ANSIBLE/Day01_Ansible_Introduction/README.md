# Day 01 - Ansible Introduction

## Overview

This module introduces Ansible fundamentals, Architecture, Agentless Automation, Inventory Basics, Control Nodes, Managed Nodes, and Environment Setup.

Ansible is an open-source automation tool used for:

- Configuration Management

- Application Deployment

- Infrastructure Automation

- Server Provisioning

- Orchestration

Ansible uses an Agentless Architecture, which means managed servers do not require special agents. Automation is performed through SSH connections.
