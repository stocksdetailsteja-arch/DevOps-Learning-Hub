# Day 01 - Interview Questions

## Basic

### Q1 What Is Ansible?

Ansible is an open-source automation and configuration management tool.

### Q2 What Is Configuration Management?

Managing and maintaining consistent system configurations.

### Q3 What Is A Control Node?

System where Ansible is installed and executed.

### Q4 What Is A Managed Node?

Remote system managed by Ansible.

## Intermediate

### Q1 Why Is Ansible Called Agentless?

Because no software agent is required on managed nodes; it communicates over SSH.

### Q2 What Is Inventory?

A file containing managed hosts and groups.

### Q3 What Is A Playbook?

A YAML file describing automation tasks.
