# Day 01 - Ansible Introduction Troubleshooting

## Scenario 1

ansible command not found

Cause:

Ansible not installed.

Resolution:

Install Ansible and verify PATH.

## Scenario 2

SSH Connection Failed

Cause:

Wrong User Or Key.

Resolution:

Verify SSH Configuration.

## Scenario 3

Inventory Not Found

Cause:

Incorrect Path.

Resolution:

Review Inventory Location.

## Scenario 4

Managed Node Unreachable

Cause:

Firewall Or Network Issue.

Resolution:

Verify Connectivity.

## Scenario 5 (5+ Years)

Automation Works On Some Servers But Fails On Others

Investigation:

- Inventory

- SSH Access

- Permissions

Resolution:

Compare Server Configurations.

## Scenario 6 (5+ Years)

Large Scale Inventory Management Problem

Investigation:

- Inventory Design

- Host Grouping

Resolution:

Implement Structured Inventory Design.

## Scenario 7 (5+ Years)

Production Deployment Failure

Investigation:

- SSH

- Inventory

- Permissions

- Logs

Resolution:

Review Deployment Workflow.
