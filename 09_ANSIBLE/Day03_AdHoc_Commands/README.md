# Day 03 - AdHoc Commands

## Overview

This module covers Ansible Ad-Hoc Commands, Modules, Remote Administration, Package Management, File Management, Service Management, and Server Automation.

Ad-Hoc Commands provide a fast way to execute operations on managed nodes without creating playbooks.
