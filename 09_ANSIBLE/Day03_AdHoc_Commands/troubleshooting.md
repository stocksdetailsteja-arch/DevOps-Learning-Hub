# Day 03 - AdHoc Commands Troubleshooting

## Scenario 1

Ping Failed

Cause:

SSH Connectivity Issue

Resolution:

Verify SSH Access.

## Scenario 2

Permission Denied

Cause:

Lack Of sudo Privileges

Resolution:

Use --become.

## Scenario 3

Package Installation Failed

Cause:

Repository Unavailable

Resolution:

Update Package Cache.

## Scenario 4

Copy Module Failed

Cause:

Source File Missing

Resolution:

Verify Source Path.

## Scenario 5 (5+ Years)

Command Works On Some Hosts Only

Investigation:

- Inventory

- SSH Access

- Permissions

Resolution:

Compare Host Configurations.

## Scenario 6 (5+ Years)

Large Scale Automation Failure

Investigation:

- Inventory Groups

- Network Connectivity

- Resource Availability

Resolution:

Validate Environment Structure.

## Scenario 7 (5+ Years)

Production Service Not Starting

Investigation:

- Service Logs

- Configuration Files

- Package Status

Resolution:

Review Application Configuration.
