# Day 03 - Lab Notes

## Objective

Learn Ansible Ad-Hoc Commands and Modules.

## Services Used

- Ping Module

- Command Module

- Shell Module

- Copy Module

- File Module

- Service Module

## Observations

- Ad-Hoc Commands are useful for quick operations.

- Modules simplify automation.

- Multiple servers can be managed simultaneously.

- SSH provides secure communication.

## Results

Successfully executed remote administration tasks.

## Lessons Learned

- Ad-Hoc Commands are useful for troubleshooting.

- Modules provide reusable functionality.

- Playbooks are better for long-term automation.
