# Day 09 - Ansible Project

## Objective

Build a complete real-world Ansible automation project that combines all Ansible concepts learned so far.

This project simulates a real DevOps environment where infrastructure and application deployment are automated using Ansible.

The project includes:

- AWS Integration
- EC2 Provisioning
- Inventory Management
- Roles
- Playbooks
- Variables
- Handlers
- Vault
- Application Deployment

## Project Scenario

A company wants to deploy a web application on AWS automatically.

Requirements:

- Create Infrastructure
- Install Nginx
- Configure Web Server
- Deploy Application
- Secure Credentials
- Validate Deployment

Everything must be automated using Ansible.
