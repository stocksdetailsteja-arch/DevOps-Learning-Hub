# Day 08 Lab Notes

## Objective

Learn Linux Package Installation, Upgrade, Verification, and Removal.

## Commands Executed

- apt update

- apt install

- apt search

- apt show

- dpkg -l

- Packages are downloaded from repositories.

- Dependencies are automatically resolved.

- Package installations can be verified.

- Verify installation.

- Understand dependencies.
