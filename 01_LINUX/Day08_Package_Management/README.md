# Day 08 - Package Management

## Overview

This module covers Linux Package Management, software installation, upgrades, repository management, dependency resolution, and troubleshooting package-related issues.

Package management is a critical skill for Linux Administrators, DevOps Engineers, Cloud Engineers, and Platform Teams.

## Learning Objectives

- Understand Package Management

- Install Software

- Upgrade Packages

- Remove Packages

- Manage Repositories

- Troubleshoot Package Failures

- Handle Dependency Issues

- Verify Installed Software
