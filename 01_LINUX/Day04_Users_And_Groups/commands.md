# Day 04 Commands

## whoami

Purpose:

Display current user.

Example:

whoami

## id

Purpose:

Display user and group information.

Example:

id

## groups

Purpose:

Display user groups.

Example:

groups

## useradd

Purpose:

Create user.

Example:

sudo useradd teja

## passwd

Purpose:

Set password.

Example:

sudo passwd teja

## usermod

Purpose:

Modify user.

Example:

sudo usermod -aG sudo teja

## groupadd

Purpose:

Create group.

Example:

sudo groupadd devops

## userdel

Purpose:

Delete user.

Example:

sudo userdel teja

## su

Purpose:

Switch user.

Example:

su teja
