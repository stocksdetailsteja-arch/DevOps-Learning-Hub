# Day 04 - Users And Groups

## Overview

This module covers Linux user and group management.

Users and Groups are essential for controlling access, security, and permissions in Linux systems.

## Learning Objectives

- Understand Linux Users

- Understand Linux Groups

- Create Users

- Create Groups

- Modify Users

- Switch Users

- Manage Passwords

- Understand Sudo Access

## Topics Covered

- What Is A User?

- Types Of Users

- What Is A Group?

- User Management

- Group Management

- Sudo Access

- Password Management

## Expected Outcome

After completing this module, you should be able to manage Linux users and groups confidently.
