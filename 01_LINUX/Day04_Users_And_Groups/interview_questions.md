# Day 04 Interview Questions

## Basic

Q1. What is a user in Linux?

Answer:

A user is an account used to access and operate the Linux system.

Q2. What is a group?

Answer:

A group is a collection of users used for easier permission management.

## Intermediate

Q1. What is the difference between root user and regular user?

Answer:

Root user has complete system access.

Regular users have limited permissions.

## Advanced

Q1. What is sudo?

Answer:

sudo allows a user to execute commands with elevated privileges.

Q2. Which file stores user information?

Answer:

/etc/passwd
