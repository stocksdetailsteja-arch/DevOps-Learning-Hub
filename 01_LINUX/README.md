# Linux Learning Path

## Overview

This section covers Linux from fundamentals to system administration.

Linux is the foundation for DevOps, Cloud Computing, Containers, Kubernetes, CI/CD, and Infrastructure Automation.

## Learning Objectives

- Understand Linux Fundamentals

- Learn Linux Architecture

- Navigate Linux File System

- Manage Users and Groups

- Control File Permissions

- Manage Processes

- Understand Networking

- Manage Software Packages

- Work with Archives and Compression

- Perform System Administration Tasks

## Modules Covered

- Day01_Linux_Introduction

- Day02_File_System

- Day03_Files_And_Directories

- Day04_Users_And_Groups

- Day05_Permissions

- Day06_Processes

- Day07_Networking

- Day08_Package_Management

- Day09_Archiving_And_Compression

- Day10_System_Administration

## Learning Outcome

After completing this Linux track, you should be able to:

- Work confidently on Linux servers

- Navigate and manage the file system

- Create and manage users

- Configure permissions

- Monitor processes

- Troubleshoot basic Linux issues

- Use Linux effectively in DevOps environments
