# Day 05 - Linux Permissions

## Overview

This module covers Linux file ownership, permissions, access control mechanisms, and special permissions.

Linux permissions are critical for system security and are heavily used in DevOps, Cloud, and Production environments.

## Learning Objectives

- Understand Ownership

- Understand User, Group, and Others

- Learn Permission Types

- Learn chmod

- Learn chown

- Learn chgrp

- Learn Numeric Permissions

- Learn Symbolic Permissions

- Learn SUID

- Learn SGID

- Learn Sticky Bit

## Topics Covered

- Ownership

- Permissions

- chmod

- chown

- chgrp

- Numeric Permissions

- Symbolic Permissions

- SUID

- SGID

- Sticky Bit

## Expected Outcome

After completing this module, you should be able to secure Linux files and troubleshoot permission-related issues in production systems.
