# Day 05 Lab Notes

## Objective

Understand Linux ownership and permissions.

## Commands Executed

- ls -l

- chmod

- chown

- chgrp

- stat

## Labs Performed

Lab 1

Created a test file.

Observations:

Default permissions were assigned by the system.

Lab 2

Changed permissions using chmod.

Example:

chmod 755 file1

Result:

Owner had full permissions.

Others had read and execute permissions.

Lab 3

Changed ownership using chown.

Result:

Ownership transferred successfully.

Lab 4

Verified permissions using ls -l.

Result:

Permission changes reflected correctly.

## Lessons Learned

- Permissions are critical for Linux security.

- Incorrect permissions often cause application failures.

- Ownership and permissions should always be verified during troubleshooting.

## Result

Successfully managed Linux permissions and ownership.
