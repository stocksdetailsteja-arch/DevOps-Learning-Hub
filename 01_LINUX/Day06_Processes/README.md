# Day 06 - Linux Processes

## Overview

This module covers Linux process management, process monitoring, job control, process priorities, signals, and production troubleshooting.

Every running program in Linux is represented as a process. DevOps Engineers regularly investigate processes while troubleshooting application failures, high CPU utilization, memory leaks, hung Jenkins jobs, container failures, and service outages.

## Learning Objectives

By the end of this module, you should be able to:

- Explain what a Linux process is

- Understand PID and PPID

- Understand parent and child processes

- Identify foreground and background processes

- Understand process states

- Monitor CPU and memory consumption

- Find processes using names and PIDs

- Manage foreground and background jobs

- Terminate processes safely

- Understand Linux signals

- Modify process priority

- Identify zombie and orphan processes

- Run processes after disconnecting from a terminal

- Troubleshoot production process issues

## Why Process Management Is Important

Process management is required when troubleshooting:

- High CPU usage

- High memory usage

- Hung applications

- Jenkins build failures

- Java application issues

- Docker container failures

- Kubernetes pod issues

- Database performance problems

- Nginx or Apache service failures

- Out-of-memory events
