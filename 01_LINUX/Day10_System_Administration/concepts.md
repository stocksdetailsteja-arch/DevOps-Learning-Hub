# Day 10 - System Administration Concepts

## What Is System Administration?

System Administration is the process of managing, maintaining, monitoring, and troubleshooting servers and operating systems.

Responsibilities include:

- User Management

- Service Management

- Monitoring

- Performance Tuning

- Security Management

- Backup Management

## System Information

Important information about a Linux system:

- Hostname

- Kernel Version

- Uptime

- CPU Information

- Memory Information

- Disk Information

## Service Management

Linux services are background programs managed by systemd.

Examples:

- ssh

- cron

- docker

- nginx

- jenkins

## Logging

Logs help administrators troubleshoot issues.

Common log locations:

- /var/log/syslog

- /var/log/auth.log

- /var/log/kern.log

## Cron Jobs

Cron is used for task scheduling.

Examples:

- Database Backup

- Cleanup Jobs

- Monitoring Scripts

- Report Generation

## Performance Monitoring

Administrators constantly monitor:

- CPU

- Memory

- Disk

- Processes

- Network

## Real World DevOps Example

Production website becomes slow.

Investigation:

- CPU Usage

- Memory Usage

- Disk Usage

- Application Logs

- Service Status
