# Day 03 Commands

## touch

Purpose:

Create empty file.

Example:

touch notes.txt

## mkdir

Purpose:

Create directory.

Example:

mkdir project

## cp

Purpose:

Copy file or directory.

Example:

cp file1.txt backup.txt

## mv

Purpose:

Move or rename files.

Example:

mv old.txt new.txt

## rm

Purpose:

Delete files.

Example:

rm sample.txt

## rm -r

Purpose:

Delete directories recursively.

Example:

rm -r project

## cat

Purpose:

Display file contents.

Example:

cat notes.txt

## head

Purpose:

View first 10 lines.

Example:

head file.txt

## tail

Purpose:

View last 10 lines.

Example:

tail file.txt
