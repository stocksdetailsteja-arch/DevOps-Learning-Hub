# Day 03 - Files And Directories

## Overview

This module focuses on working with files and directories in Linux.

You will learn how to create, view, copy, move, rename, and delete files and directories.

## Learning Objectives

- Create files

- Create directories

- Copy files and directories

- Move files and directories

- Rename files and directories

- Delete files and directories

- View file contents

- Understand file operations used in DevOps

## Topics Covered

- Touch Command

- Mkdir Command

- Cp Command

- Mv Command

- Rm Command

- Cat Command

- More Command

- Less Command

- Head Command

- Tail Command

## Expected Outcome

After completing this module, you should be able to manage files and directories confidently in Linux.
