# Day 03 - Files And Directories Concepts

## Files In Linux

A file is a container used to store data.

Examples:

- notes.txt

- app.log

- script.sh

- README.md

Everything in Linux is treated as a file.

## Directories In Linux

Directories are used to organize files.

Directories are also called folders.

Example:

Documents

├── notes.txt

├── project.docx

└── images

## Why File Management Is Important?

DevOps Engineers work with:

- Configuration files

- Log files

- Application files

- Scripts

- Deployment files

Efficient file management is an essential skill.

## Common File Operations

- Create

- View

- Copy

- Move

- Rename

- Delete

- Search

## Real World Example

A DevOps Engineer may:

- Create deployment scripts

- Copy configuration files

- Move backup files

- Delete old logs

- View application logs

Daily work heavily depends on file management skills.
