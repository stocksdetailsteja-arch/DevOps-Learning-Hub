# Day 03 Interview Questions

## Basic

Q1. Which command creates a file?

Answer:

touch

Q2. Which command creates a directory?

Answer:

mkdir

Q3. Which command displays file contents?

Answer:

cat

## Intermediate

Q1. Difference between cp and mv?

Answer:

cp copies files.

mv moves or renames files.

## Advanced

Q1. Difference between rm and rm -r?

Answer:

rm deletes files.

rm -r deletes directories recursively.
