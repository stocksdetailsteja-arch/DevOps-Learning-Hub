## Important Definitions

Linux

Linux is an open-source operating system kernel created by Linus Torvalds in 1991.

Kernel

Kernel is the core component of Linux responsible for managing system resources and communication between hardware and software.

Shell

Shell is a command-line interpreter that allows users to interact with the operating system.

Distribution

A Linux Distribution (Distro) is a complete operating system built around the Linux Kernel.

Examples:

- Ubuntu

- Debian

- RHEL

- Rocky Linux

- Fedora
