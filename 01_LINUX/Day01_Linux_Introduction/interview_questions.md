# Day 01 Interview Questions

## Basic

Q1. What is Linux?

Answer: Linux is an open-source operating system kernel created by Linus Torvalds in 1991.

Q2. Who created Linux?

Answer: Linus Torvalds.

Q3. What is a Linux Distribution?

Answer: A complete operating system built around the Linux Kernel.

## Intermediate

Q1. Difference between Kernel and Shell?

Answer:

Kernel: Core component of Linux.

Shell: Command interpreter that communicates with Kernel.

## Advanced

Q1. Why is Linux important in DevOps?

Answer:

Most DevOps tools such as Docker, Kubernetes, Jenkins and cloud servers run on Linux.
