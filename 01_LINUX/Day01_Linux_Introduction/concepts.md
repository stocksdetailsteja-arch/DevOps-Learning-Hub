# Day 01 - Linux Introduction

## What Is Linux?

Linux is a free and open-source operating system kernel created by Linus Torvalds in 1991.

An operating system acts as a bridge between:

- Hardware

- Applications

- Users

Linux powers:

- Servers

- Cloud Platforms

- Mobile Devices (Android)

- Supercomputers

- Containers

- IoT Devices

Today, Linux is the most widely used operating system in cloud and DevOps environments.

## Why Is Linux Important?

Linux is important because it provides:

- Stability

- Security

- Flexibility

- Scalability

- Performance

Most modern technologies run on Linux, including:

- AWS EC2 Instances

- Docker Containers

- Kubernetes Clusters

- Jenkins Servers

- Web Servers

- Databases

Because of this, Linux knowledge is considered the foundation of DevOps.

## History Of Linux

1983

Richard Stallman started the GNU Project to create a free Unix-like operating system.

1991

Linus Torvalds created the Linux Kernel.

1992

Linux was released under the GNU General Public License (GPL).

1990s

Linux distributions such as Red Hat and Debian became popular.

2000s

Linux became widely adopted in enterprise environments.

Today

Linux powers most cloud infrastructure and modern DevOps platforms.

## Open Source Software

Linux is Open Source.

Open Source means:

- Source code is publicly available

- Anyone can view the code

- Anyone can modify the code

- Anyone can distribute the code according to license terms

Benefits:

- Transparency

- Community Support

- Security Improvements

- Faster Innovation

## Linux Distributions

A Linux Distribution (Distro) is a complete operating system built around the Linux Kernel.

Popular distributions include:

- Ubuntu

- Debian

- Red Hat Enterprise Linux (RHEL)

- CentOS

- Rocky Linux

- AlmaLinux

- Fedora

- SUSE Linux

## Linux Architecture

Linux architecture consists of:

Hardware

Kernel

Shell

User Applications

Hardware

Physical resources such as:

- CPU

- Memory

- Disk

- Network Interface

Kernel

The core of Linux.

Responsibilities:

- Process Management

- Memory Management

- Device Management

- File System Management

Shell

The interface between user and kernel.

Examples:

- Bash

- Zsh

- Ksh

Shell accepts user commands and passes them to the kernel.

Applications

Programs used by users.

Examples:

- Vim

- Git

- Docker

- Jenkins

- Java Applications

## What Is A Kernel?

Kernel is the heart of Linux.

Functions:

- Process Scheduling

- Memory Management

- Hardware Communication

- Security Enforcement

- Resource Allocation

Without the kernel, Linux cannot function.

## What Is A Shell?

Shell is a command interpreter.

Purpose:

- Accept commands from users

- Execute commands

- Display results

Most common shell:

- Bash (Bourne Again Shell)

Examples:

pwd

ls

cd

mkdir

These commands are executed through the shell.

## Linux In DevOps

Linux plays a critical role in DevOps.

Examples:

- Docker containers usually run Linux

- Kubernetes worker nodes commonly run Linux

- AWS EC2 uses Linux extensively

Common DevOps tasks on Linux:

- Server Administration

- Application Deployment

- Log Analysis

- Automation

- Monitoring

- Linux is the foundation of DevOps
