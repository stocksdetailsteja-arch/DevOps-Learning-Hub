# Day 01 Commands

## Command 1 - pwd

Purpose:

Print current working directory.

Syntax:

pwd

Example:

pwd

Sample Output:

/home/ubuntu

## Command 2 - whoami

Purpose:

Displays current logged-in user.

Syntax:

whoami

Example:

whoami

Sample Output:

ubuntu

## Command 3 - hostname

Purpose:

Displays system hostname.

Syntax:

hostname

Example:

hostname

## Command 4 - uname

Purpose:

Displays operating system information.

Syntax:

uname

Example:

uname

## Command 5 - uname -a

Purpose:

Displays complete kernel information.

Syntax:

uname -a

## Command 6 - date

Purpose:

Displays current date and time.

Syntax:

date

## Command 7 - cal

Purpose:

Displays calendar.

Syntax:

cal

## Key Takeaways

- pwd → Current directory

- whoami → Current user

- hostname → System name

- uname → OS information

- date → Current date and time

- cal → Calendar
