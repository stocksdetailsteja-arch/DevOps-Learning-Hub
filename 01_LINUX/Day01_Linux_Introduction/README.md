# Day 01 - Linux Introduction

## Overview

This module introduces Linux fundamentals, Linux history, Linux architecture, Linux distributions, and the role of Linux in DevOps.

Linux is one of the most important technologies for DevOps Engineers because most cloud platforms, servers, containers, and automation tools run on Linux.

## Learning Objectives

By the end of this module, you should be able to:

- Understand what Linux is

- Understand the history of Linux

- Explain why Linux is important

- Identify major Linux distributions

- Understand Linux architecture

- Explain the role of the Kernel

- Explain the role of the Shell

- Understand Linux usage in DevOps

## Why Learn Linux?

Linux is the foundation for:

- AWS Cloud

- Docker

- Kubernetes

- Jenkins

- Terraform

- Ansible

- Monitoring Tools

Most production servers run Linux.

Understanding Linux is a mandatory skill for every DevOps Engineer.
