# Day 02 Troubleshooting

## Problem

No such file or directory

Example:

cd abc

Cause:

Directory does not exist.

Resolution:

Check directory name using:

ls

## Problem

bash: tree: command not found

Cause:

Tree package not installed.

Resolution:

sudo apt install tree -y

## Problem

Permission denied

Cause:

Insufficient permissions.

Resolution:

Use proper permissions or sudo.
