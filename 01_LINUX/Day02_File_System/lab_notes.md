# Day 02 Lab Notes

## Lab Objective

Understand Linux File System navigation and directory hierarchy.

## Commands Executed

- pwd

- ls

- ls -l

- ls -la

- cd

- tree

- file

## Observations

- Linux uses a hierarchical structure.

- Everything starts from Root directory (/).

- Hidden files begin with a dot (.).

- Relative and absolute paths are important.

Successfully navigated Linux file system and explored directory hierarchy.
