# Day 02 - Linux File System

This module explains the Linux File System, directory hierarchy, file types, and navigation concepts.

## Learning Objectives

- Understand Linux File System

- Learn Directory Structure

- Learn Absolute and Relative Paths

- Navigate Linux Directories

## Topics Covered

- Linux File System

- Directory Hierarchy

- Root Directory

- Important System Directories

- File Types

- Path Types

- Navigation Commands

## Expected Outcome

After completing this module, you should be able to:

- Navigate any Linux directory

- Understand Linux directory structure

- Work with file paths confidently
