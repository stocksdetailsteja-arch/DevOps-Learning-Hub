## Important Directories

- / → Root Directory

- /home → User Home Directories

- /root → Root User Home

- /etc → Configuration Files

- /usr → User Programs

- /var → Variable Data

- /tmp → Temporary Files

- /dev → Device Files

- /proc → Process Information

- /boot → Boot Files

## Quick Revision

Linux File System = Method of organizing files.

Root Directory = /

Absolute Path = Starts from /

Relative Path = Starts from current directory

Everything in Linux is treated as a file.

## Key Takeaways

- Linux uses a tree structure.

- Root directory is the starting point.

- Knowing directory structure is critical for DevOps.

- Navigation commands are used daily by DevOps Engineers.
