# Day 02 Interview Questions

## Basic Questions

Q1. What is a Linux File System?

Answer:

A Linux File System is the structure used by the operating system to organize and manage files and directories.

Q2. What is the root directory?

Answer:

The root directory (/) is the top-level directory in Linux.

Q3. What is the difference between absolute and relative path?

Answer:

Absolute Path:

Starts from root (/)

Example:

/home/ubuntu

Relative Path:

Starts from current directory

Example:

Documents/file.txt

## Intermediate Questions

Q1. What is the purpose of /etc directory?

Answer:

Stores system configuration files.

Q2. What is the purpose of /var directory?

Answer:

Stores changing data such as logs and spool files.

## Advanced Questions

Q1. Why is Linux called a hierarchical file system?

Answer:

Because all files and directories are organized in a tree-like structure beginning from root (/).
