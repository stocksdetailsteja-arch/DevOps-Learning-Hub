# Day 02 - Linux File System Concepts

## What Is A File System?

A File System is a method used by an operating system to organize, store, retrieve, and manage data on storage devices.

The File System helps Linux:

- Store files

- Organize directories

- Manage permissions

- Track file locations

Everything in Linux is treated as a file.

Examples:

- Regular Files

- Directories

- Devices

- Processes

## Linux Directory Hierarchy

Linux follows a hierarchical directory structure.

The starting point is:

/

This is called the Root Directory.

All files and directories exist under Root.

Structure:

/

├── home

├── root

├── etc

├── usr

├── var

├── tmp

├── dev

├── proc

└── boot
