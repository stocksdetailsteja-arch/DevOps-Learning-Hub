# Day 02 Commands

## Command 1 - pwd

Purpose:

Display current working directory.

Syntax:

pwd

Example:

pwd

## Command 2 - ls

Purpose:

List files and directories.

Syntax:

ls

Example:

ls

## Command 3 - ls -l

Purpose:

Display detailed file information.

Syntax:

ls -l

## Command 4 - ls -la

Purpose:

Display all files including hidden files.

Syntax:

ls -la

## Command 5 - cd

Purpose:

Change directory.

Syntax:

cd directory_name

Examples:

cd /home

cd ..

cd ~

## Command 6 - tree

Purpose:

Display directory structure.

Syntax:

tree

## Command 7 - file

Purpose:

Determine file type.

Syntax:

file filename

Example:

file README.md

## Key Takeaways

- pwd → Present Working Directory

- ls → List files

- cd → Change directory

- tree → Directory hierarchy

- file → File type identification
