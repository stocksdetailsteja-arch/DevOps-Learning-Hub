# Day 07 - Linux Networking

## Overview

This module covers Linux networking fundamentals, network interfaces, IP addressing, routing, DNS, ports, protocols, connectivity testing, and production network troubleshooting.

Networking knowledge is essential for DevOps Engineers because AWS services, Docker containers, Kubernetes workloads, Jenkins agents, monitoring systems, databases, APIs, and applications communicate through networks.

## Learning Objectives

By the end of this module, you should be able to:

- Understand networking fundamentals

- Understand the OSI and TCP/IP models

- Identify network interfaces and IP addresses

- Differentiate public and private IP addresses

- Understand subnet masks and default gateways

- Understand TCP and UDP

- Understand ports and common application protocols

- Understand DNS resolution

- Inspect routing tables

- Test host and port connectivity

- Inspect listening ports and active connections

- Troubleshoot DNS, routing, firewall, and application connectivity problems

- Investigate production network incidents systematically
