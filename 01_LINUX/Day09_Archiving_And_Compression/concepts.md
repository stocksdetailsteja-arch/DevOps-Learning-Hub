# Day 09 - Archiving And Compression Concepts

## What Is Archiving?

Archiving combines multiple files and directories into a single file.

Example:

project/

↓

project.tar

## What Is Compression?

Compression reduces file size.

Benefits:

- Lower Storage Usage

- Faster Transfers

- Smaller Backups

## Difference Between Archiving And Compression

Archiving:

- Combines files

Compression:

- Reduces size

Common Example:

project.tar.gz

Tar Archive

Gzip Compression

## Common Formats

- .tar

- .tar.gz

- .tgz

- .tar.bz2

- .zip

## Backup Flow

Application Data

↓

Archive

↓

Compress

↓

Store

↓

Restore
