# Day 07 - Interview Questions

## Beginner Level

### What is Amazon CloudWatch?

Amazon CloudWatch is AWS's monitoring and observability service. 【1-4a956b】【4-1e7e89】

### What can CloudWatch monitor?

- EC2
- RDS
- Lambda
- Load Balancers
- Application Logs

### What are CloudWatch Metrics?

Numerical measurements collected from AWS services. 【1-4a956b】

### What is a CloudWatch Alarm?

A threshold-based monitoring rule. 【1-4a956b】

### What is a Dashboard?

A visual monitoring interface displaying metrics and alarms. 【2-c1f806】

## Intermediate Level

### What are Namespaces?

Logical groupings of metrics.

Examples:

- AWS/EC2
- AWS/RDS
- AWS/Lambda

### What are Dimensions?

Attributes identifying specific resources.

### Why use CloudWatch Agent?

To collect:

- Memory Usage
- Disk Metrics
- Custom Logs

### Difference between Metrics and Logs?

Metrics:

Numerical performance data.

Logs:

Detailed event records.

### What is SNS?

Notification service used by CloudWatch alarms.
