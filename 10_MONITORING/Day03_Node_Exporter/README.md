# Day 03 - Node Exporter

## Objective

Learn how to monitor Linux server infrastructure using Node Exporter and Prometheus.

Node Exporter is one of the most commonly used Prometheus exporters and is responsible for exposing Linux operating system metrics for monitoring.

Using Node Exporter, DevOps teams can monitor:

- CPU Usage
- Memory Usage
- Disk Usage
- Filesystem Usage
- Network Traffic
- System Load
- Running Processes
- Host Statistics

## Why Node Exporter?

Prometheus cannot directly collect Linux operating system metrics.

Node Exporter exposes Linux system metrics through an HTTP endpoint that Prometheus scrapes periodically.

## Real World Use Cases

- Linux Server Monitoring
- EC2 Monitoring
- Kubernetes Node Monitoring
- Docker Host Monitoring
- Capacity Planning
- Performance Analysis

## Expected Outcome

By the end of this lesson you will be able to:

- Install Node Exporter
- Configure Prometheus Integration
- Monitor Linux Metrics
- Create Infrastructure Dashboards
- Troubleshoot Exporter Issues
