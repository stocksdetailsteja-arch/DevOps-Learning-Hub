# Day 04 - PromQL

## Objective

Learn PromQL (Prometheus Query Language), the powerful query language used to search, analyze, aggregate, and visualize metrics stored in Prometheus.

PromQL is one of the most important skills for DevOps Engineers, SREs, Platform Engineers, and Cloud Engineers because every Grafana dashboard and most Prometheus alerts depend on PromQL queries.

In this module you will learn:

- Metric Selectors
- Labels
- Instant Vectors
- Range Vectors
- Aggregation Operators
- Functions
- Rate Calculations
- Alert Queries
- Dashboard Queries
- Performance Monitoring Queries

## Why PromQL?

Prometheus stores raw metrics.

PromQL helps you:

- Search metrics
- Filter metrics
- Aggregate data
- Calculate rates
- Build dashboards
- Create alerts
- Investigate incidents

## Real World Use Cases

- CPU Utilization Monitoring
- Memory Usage Monitoring
- Disk Monitoring
- Network Monitoring
- API Error Tracking
- Application Latency Monitoring
- Capacity Planning

## Expected Outcome

By the end of this lesson you will be able to:

- Write PromQL queries
- Build Grafana dashboards
- Create alert expressions
- Analyze infrastructure metrics
- Troubleshoot production incidents
