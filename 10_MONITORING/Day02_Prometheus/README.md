# Day 02 - Prometheus

## Objective

Learn Prometheus, one of the most widely used open-source monitoring and alerting systems in modern DevOps environments.

Prometheus is used to collect, store, query, and alert on time-series metrics from servers, applications, containers, and cloud infrastructure. It uses a pull-based architecture and provides powerful querying through PromQL. 【1-79a278】【2-7866c1】

In this module you will learn:

- Prometheus Architecture
- Prometheus Server
- Targets
- Exporters
- Jobs
- Labels
- Time-Series Metrics
- Scrape Process
- Prometheus Configuration
- Prometheus UI
- Monitoring Workflow

## Why Prometheus?

Traditional monitoring solutions struggle in dynamic cloud-native environments.

Prometheus provides:

- Pull-based Monitoring
- Service Discovery
- Time-Series Database
- Powerful Query Engine
- Alerting Integration
- Kubernetes Monitoring Support

## Real World Use Cases

- Linux Server Monitoring
- Kubernetes Monitoring
- Docker Monitoring
- AWS EC2 Monitoring
- Microservices Monitoring
- Application Performance Monitoring
