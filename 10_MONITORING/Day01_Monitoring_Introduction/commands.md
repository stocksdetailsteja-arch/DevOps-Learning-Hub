# Day 01 - Monitoring Commands

## Check CPU Usage

top

## Check Memory Usage

free -h

## Check Disk Usage

df -h

## Check Running Processes

ps -ef

## Check System Load

uptime

## Check Network Connections

ss -tulpn

## Check System Logs

journalctl

## View Recent Logs

journalctl -n 50

## Monitor Disk Activity

iostat

## Monitor Network Statistics

netstat -an

## Check Server Availability

ping google.com

## View Host Information

hostnamectl
