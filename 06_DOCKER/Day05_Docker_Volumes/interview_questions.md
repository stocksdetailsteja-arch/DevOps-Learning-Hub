# Day 05 - Interview Questions

## Basic

### Q1 What Is A Docker Volume?

Persistent storage managed by Docker.

### Q2 Why Use Volumes?

To retain data beyond container lifecycle.

### Q3 What Is A Bind Mount?

Host directory mapped into container.

### Q4 How Do You List Volumes?

docker volume ls

## Intermediate

### Q1 Difference Between Volume And Bind Mount?

Volume:

Docker Managed

Bind Mount:

Host Managed

### Q2 Why Are Volumes Important?

Enable persistent application data.

### Q3 Why Use Named Volumes?

Easier management and portability.

## Advanced (5+ Years)

### Q1 MySQL Container Deleted. How Can Data Survive?

Answer:

Store database files inside Docker Volumes.

### Q2 How Would You Design Storage For Production Containers?

Answer:

Persistent Volumes

Backups

Monitoring

Recovery Plan

### Q3 Why Are Volumes Preferred For Databases?

Answer:

Databases require persistent data storage.

### Q4 How Do You Backup Volumes?

Answer:

Create Backup

Store Securely

Validate Restore Procedure

### Q5 What Are Common Storage Problems?

Answer:

- Disk Full

- Missing Backups

- Volume Misconfiguration

- Data Corruption
