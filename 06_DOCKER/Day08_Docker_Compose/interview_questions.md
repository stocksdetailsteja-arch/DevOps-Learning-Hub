# Day 08 - Interview Questions

## Basic

### Q1 What Is Docker Compose?

Tool for managing multi-container applications.

### Q2 What Is compose.yaml?

Configuration file used by Docker Compose.

### Q3 How Do You Start Compose Services?

docker compose up

### Q4 How Do You Stop Compose Services?

docker compose down

## Intermediate

### Q1 Why Use Docker Compose?

Simplifies deployment and management of multiple containers.

### Q2 How Do Services Communicate?

Using service names through Docker networking.

### Q3 Why Use Volumes In Compose?

For persistent data storage.

## Advanced (5+ Years)

### Q1 Why Is Docker Compose Popular For Development?

Answer:

- Easy Setup

- Multi-Service Support

- Simplified Networking

- Fast Testing

### Q2 Compose Stack Starts But Application Fails. What Will You Check?

Answer:

Compose Logs

Service Dependencies

Environment Variables

Network Connectivity

Volume Configuration

### Q3 How Would You Design A Three-Tier Application?

Answer:

Frontend

↓

Backend

↓

Database

Using Compose Networks And Volumes.

### Q4 Why Use Environment Variables?

Answer:

Separate Configuration From Code.

### Q5 How Do Enterprises Use Compose?

Answer:

- Development Environments

- Testing

- CI/CD Validation

- Local Application Stacks
