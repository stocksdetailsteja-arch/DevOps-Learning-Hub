# Day 08 - Docker Compose

## Overview

This module covers Docker Compose, compose.yaml, Multi-Container Applications, Service Communication, Environment Variables, Volumes, Networks, and Application Stack Management.

Docker Compose allows multiple containers to be managed as a single application.

- Configure Service Communication

- Use Volumes In Compose
