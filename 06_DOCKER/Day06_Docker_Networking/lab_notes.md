# Day 06 - Lab Notes

## Objective

Learn Docker Networking and Container Communication.

## Services Used

- Docker Networks

- Containers

- Docker CLI

## Observations

- Containers communicate through networks.

- Bridge network is default.

- Port mapping exposes applications.

- DNS simplifies communication.

## Results

Successfully configured Docker Networks.

## Lessons Learned

- Use custom networks for applications.

- Use DNS names rather than IP addresses.

- Validate connectivity early.
