i# Day 01 - Docker Introduction

## Overview

This module introduces Docker and containerization fundamentals.

Docker is a platform used to package applications and their dependencies into lightweight, portable containers.

Containers help solve:

- Environment Issues

- Dependency Conflicts

- Deployment Problems

- Portability Challenges

- Inconsistent Runtime Behavior
