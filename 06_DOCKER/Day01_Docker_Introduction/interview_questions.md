# Day 01 - Interview Questions

## Basic

### Q1 What Is Docker?

Docker is a containerization platform used to package applications and dependencies into portable containers.

### Q2 What Is A Container?

Lightweight isolated runtime environment.

### Q3 What Is Docker Image?

Template used to create containers.

### Q4 What Is Docker Registry?

Storage location for Docker images.

## Intermediate

### Q1 Difference Between Container And VM?

Container:

Shares Host Kernel

VM:

Requires Guest OS

### Q2 Why Is Docker Important?

Provides consistency and portability.

### Q3 What Is Docker Engine?

Core service responsible for running containers.

## Advanced (5+ Years)

### Q1 Why Did Containers Become Popular?

Answer:

- Faster Deployment

- Lightweight Architecture

- Better Resource Usage

- Environment Consistency

- CI/CD Integration

### Q2 What Problem Does Docker Solve?

Answer:

Development Environment

≠

Production Environment

Docker guarantees consistency between environments.

### Q4 Why Are Containers More Efficient Than VMs?

Answer:

Containers share host operating-system resources rather than running a dedicated guest OS for every application.
