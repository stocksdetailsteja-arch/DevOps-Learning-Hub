# Day 10 - Interview Questions

## Basic

### Q1 What Is A Multi-Stage Docker Build?

A Docker build strategy that separates build and runtime stages.

### Q2 Why Use Docker Compose?

Manage multiple containers together.

### Q3 Why Use Volumes?

Store data persistently.

## Intermediate

### Q1 Why Are Multi-Stage Builds Important?

Reduce image size and improve security.

### Q2 Why Use Non-Root Containers?

Reduce security risks.

### Q3 Why Use Monitoring?

Detect issues early.
