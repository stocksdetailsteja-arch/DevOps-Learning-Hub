# Day 04 - Docker Containers Troubleshooting

## Scenario 1

Container Exited Immediately

Cause:

Application Failure

Resolution:

Review Logs.

## Scenario 2

Cannot Access Container

Cause:

Container Not Running

Resolution:

Check Container Status.

## Scenario 3

Container Removal Failed

Cause:

Container Still Running

Resolution:

Stop Container First.

## Scenario 4

Logs Not Available

Cause:

Container Never Started Correctly

Resolution:

Review Startup Configuration.

## Scenario 5 (5+ Years)

Production Container Crash

Investigation:

- Logs

- Resource Utilization

- Application Errors

Resolution:

Identify Root Cause And Redeploy.

## Scenario 6 (5+ Years)

High Memory Usage

Investigation:

- Application Behavior

- Container Metrics

Resolution:

Optimize Application.

## Scenario 7 (5+ Years)

Container Running But Service Not Accessible

Investigation:

- Ports

- Networking

- Firewall

- Application Listener

Resolution:

Validate Network Configuration.
