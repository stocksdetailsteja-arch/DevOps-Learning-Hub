# Day 04 - Docker Containers Commands

## Run Nginx Container

docker run nginx

Screenshot:

01_run_nginx.png

## Run Container In Background

docker run -d nginx

Screenshot:

02_background_container.png

## List Running Containers

docker ps

Screenshot:

03_running_containers.png

## List All Containers

docker ps -a

04_all_containers.png

Screenshot:

05_stop_container.png

## Start Container

Screenshot:

06_start_container.png

## Restart Container

Screenshot:

07_restart_container.png

Screenshot:

08_container_logs.png

09_exec_container.png
