# Day 04 - Lab Notes

## Objective

Learn Docker Container creation and management.

## Services Used

- Docker Images

- Docker Containers

- Docker CLI

## Observations

- Containers start from images.

- Containers can be stopped and restarted.

- Logs assist troubleshooting.

- Interactive mode provides shell access.

## Results

Successfully created, managed, and removed Docker containers.

## Lessons Learned

- Containers are lightweight.

- Containers are ephemeral by default.

- Logs are important for troubleshooting.
