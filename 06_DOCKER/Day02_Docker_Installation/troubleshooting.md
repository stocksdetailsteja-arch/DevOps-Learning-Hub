# Day 02 - Docker Installation Troubleshooting

## Scenario 1

docker command not found

Cause:

Docker Not Installed

Resolution:

Install Docker Package.

## Scenario 2

Cannot Connect To Docker Daemon

Cause:

Docker Service Stopped

Resolution:

Start Docker Service.

## Scenario 3

Permission Denied

Cause:

User Access Issue

Resolution:

Review Docker Permissions.

## Scenario 4

Docker Service Failed

Cause:

Configuration Or Package Issue

Resolution:

Review Service Logs.

## Scenario 5 (5+ Years)

Docker Service Randomly Stops

Investigation:

- Logs

- Resources

- System Health

Resolution:

Identify Root Cause.

## Scenario 6 (5+ Years)

Container Cannot Start After Installation

Investigation:

- Daemon Health

- Runtime Errors

- Resource Availability

Resolution:

Review Docker Logs.

## Scenario 7 (5+ Years)

CI/CD Cannot Access Docker

Investigation:

- Jenkins Permissions

- Docker Group

- Service State

Resolution:

Correct Access Configuration.
