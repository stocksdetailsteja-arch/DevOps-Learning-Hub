# Day 09 - Interview Questions

## Basic

### Q1 What Is Application Containerization?

Packaging application and dependencies into a container.

### Q2 Why Use Docker For Projects?

Consistency and portability.

### Q3 What Is Deployment Validation?

Verification that the application functions correctly.

### Q4 What Is The Role Of Dockerfile?

Defines image creation process.
