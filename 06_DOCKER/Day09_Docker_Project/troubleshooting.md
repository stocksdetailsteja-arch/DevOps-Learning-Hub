# Day 09 - Docker Project Troubleshooting

## Scenario 1

Image Build Failed

Cause:

Dockerfile Error

Resolution:

Review Dockerfile.

## Scenario 2

Container Failed To Start

Cause:

Application Failure

Resolution:

Review Logs.

## Scenario 3

Application Unreachable

Cause:

Port Mapping Issue

Resolution:

Verify Network Configuration.

## Scenario 4

Data Not Persisting

Cause:

Volume Missing

Resolution:

Configure Volume.

## Scenario 5 (5+ Years)

Production Deployment Failure

Investigation:

- Logs

- Networks

- Volumes

- Application Configuration

Resolution:

Identify Root Cause.

## Scenario 6 (5+ Years)

Container Restarts Repeatedly

Investigation:

- Startup Process

- Application Logs

- Resource Availability

Resolution:

Fix Application Startup Issue.

## Scenario 7 (5+ Years)

High Resource Consumption

Investigation:

- CPU

- Memory

- Container Metrics

Resolution:

Optimize Application And Image.
