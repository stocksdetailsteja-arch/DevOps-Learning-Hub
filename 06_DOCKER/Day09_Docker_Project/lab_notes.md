# Day 09 - Lab Notes

## Objective

Containerize an application using Docker.

## Services Used

- Docker Engine

- Dockerfile

- Images

- Containers

## Observations

- Docker simplifies deployments.

- Images package applications.

- Containers execute workloads.

- Validation confirms deployment success.

## Results

Successfully containerized and executed application.

## Lessons Learned

- Validate before production deployment.

- Keep images optimized.

- Review logs regularly.
